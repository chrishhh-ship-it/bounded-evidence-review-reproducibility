# PRISMA指南对系统综述结构的影响及支持其遵循的计算工具：基于摘要级证据的初步分析

**报告说明**：本报告基于提供的8篇文献摘要进行证据合成。此为方法1试点，仅基于摘要级证据，未进行全文阅读，结论需谨慎解读。

## 1. 检索与筛选概览
本次分析基于一个包含8篇文献的冻结试点语料库。这些文献发表于2022年至2025年间，均提及PRISMA指南或系统综述自动化工具。文献类型包括范围综述[1, 2]和遵循PRISMA指南的系统综述[3, 4, 5, 6, 7, 8]。筛选出的文献共同指向两个核心关联点：PRISMA指南作为系统综述的方法学框架，以及计算工具在支持该框架实施中的应用。

## 2. 核心主题与证据
证据揭示了两个相互关联的核心主题：

**PRISMA指南作为系统综述的结构化框架**
多篇文献表明，PRISMA指南被广泛用作实施系统综述的标准方法学协议，为其提供了明确的结构。具体应用包括：
- 作为系统综述的指导方法[3, 7, 8]。
- 提供具体的报告规范，如PRISMA 2020指南[5, 7, 8]。
- 被整合到计算辅助的工作流程中，以增强综述的透明度与可重复性[4]。

**支持PRISMA遵循与系统综述自动化的计算工具**
多篇文献指出，一系列计算工具被开发用于支持系统综述的自动化，这间接或直接有助于遵循PRISMA指南所要求的系统化、透明化流程。工具类型包括：
- **专用自动化软件**：如Rayyan、DistillerSR、RobotAnalyst用于文献筛选；Abstractr、BIBOT用于摘要生成或信息提取；NetMetaXL用于Meta分析[1, 2]。
- **编程语言与环境**：R软件被用于支持系统综述的自动化[1, 2]。
- **人工智能与大型语言模型（LLMs）**：LLMs（如ChatGPT、GPT-4o）正作为新兴工具出现，用于辅助系统综述中的筛选、数据提取和清洗环节[6]。CASMA工作流则整合了模糊匹配和正则表达式等技术[4]。
- **文献管理平台**：如Covidence及其LLM插件被用于系统综述的筛选与提取流程[6]。

## 3. 证据支持的研究方向
基于摘要证据，可识别出以下研究方向：
1.  **计算工具与PRISMA流程的深度整合**：研究如何将自动化工具（如LLMs、模糊匹配算法）更无缝地嵌入PRISMA指南的各个阶段（如检索、筛选、数据提取），以提升效率与合规性[4, 6]。
2.  **新兴AI技术在证据合成中的应用评估**：探索大型语言模型等AI技术在系统综述中的实际效用、准确性及其对遵循PRISMA等标准方法学的影响[5, 6]。
3.  **跨领域系统综述的方法学实践**：在不同学科领域（如医疗AI[3]、能源政策[8]、社会科学[7]、信息技术[5]）中应用和验证PRISMA指南的适用性及具体挑战。
4.  **自动化工具的局限性与优化**：尽管工具潜力被认可，但其局限性（如准确性、可靠性）是需要进一步研究的关键问题[1]。

## 4. 摘要级证据的局限
本报告的结论受到以下源自摘要信息的局限：
- **细节缺失**：摘要未提供工具如何具体支持PRISMA合规性的操作细节，也未说明PRISMA指南塑造系统综述结构的具体机制[1, 2, 4]。
- **方法学深度不足**：摘要虽提及使用PRISMA，但未深入描述其如何指导综述结构设计、偏倚风险评估或报告条目填写[3, 5, 7, 8]。
- **工具效能证据缺乏**：摘要指出工具有“潜力”或“支持”自动化，但未提供关于其有效性、效率或对综述质量影响的具体评估数据或比较结果[1, 2, 6]。
- **局限性信息不完整**：多数摘要未明确列出研究的局限性，或相关信息被截断[2]，这影响了对证据强度的判断。

## 5. 谨慎结论
基于现有摘要级证据，可以初步得出以下谨慎结论：
1.  PRISMA指南被多个学科领域的系统综述采纳为标准方法学框架，为其提供了结构化的报告和 conduct 协议[3, 5, 7, 8]。
2.  一系列计算工具，从专用软件到新兴的大型语言模型，被认为具有支持系统综述自动化流程的潜力，这可能有助于实现PRISMA指南所倡导的系统性和透明性[1, 2, 4, 6]。
3.  将PRISMA指南与计算辅助技术（如CASMA工作流）相结合，是一个旨在提高系统综述效率、透明度和可重复性的新兴研究方向[4]。
4.  必须注意，当前摘要证据未充分阐明这些计算工具在确保PRISMA合规性方面的具体效能、可靠性及局限性[1, 2]。更深入的评估需要依赖全文分析。
