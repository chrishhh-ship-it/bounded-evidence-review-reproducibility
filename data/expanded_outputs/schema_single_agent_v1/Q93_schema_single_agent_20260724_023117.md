# 跨模型与同模型 ARL 性能差距的理论解释：基于摘要级证据的合成分析

## 1. 检索与筛选概览

本合成基于给定的 8 篇摘要级证据，旨在从理论上解释跨模型 ARL（如 DeepSeek 写作 + Kimi 审阅）与同模型 ARL 的性能差距。检索范围涵盖 2025—2026 年发表的预印本、期刊论文及会议文献，涉及多智能体系统（MAS）、单智能体系统（SAS）、信息论分析及领域应用。经筛选，直接相关的核心证据为 [5]，该文提出了信息论解释框架；辅助证据 [2][3][4] 提供了多智能体协作的实证背景；其余文献 [1][6][7][8] 虽涉及 LLM 应用，但未直接讨论跨模型 vs 同模型 ARL 问题，仅作为领域背景参考。

## 2. 核心主题与证据

### 2.1 信息论视角：数据处理不等式与效率损失

[5] 提出了一个信息论论证，基于数据处理不等式（Data Processing Inequality）指出：在固定推理令牌预算且完美利用上下文的前提下，单智能体系统比多智能体系统更具信息效率。该理论预测，多智能体系统只有在单智能体有效上下文利用率下降或投入更多计算资源时，才可能具有竞争力 [5]。这一框架直接适用于解释跨模型 ARL 的性能差距：当写作与审阅由不同模型承担时，信息需要在两个独立模型之间传递，每个模型对上下文的利用效率可能不同，且传递过程本身可能引入信息损失或噪声，从而降低整体信息效率。

### 2.2 实证验证：同模型 MAS 未必优于 SAS

[5] 在 Qwen3、DeepSeek-R1-Distill-Llama 和 Gemini 2.5 三个模型系列上进行了受控实验，发现在推理令牌数相等的情况下，单智能体系统在多跳推理任务上始终匹配或优于多智能体系统。该研究进一步指出，许多 MAS 的所谓优势实际上可归因于未受控的计算量增加和上下文效应，而非架构本身的优势 [5]。这一发现暗示，即使采用同模型（如 DeepSeek 写作 + DeepSeek 审阅），MAS 相对于 SAS 的优势也有限；跨模型场景（DeepSeek + Kimi）可能进一步放大信息传递效率损失。

### 2.3 跨模型协作的额外挑战

[2] 展示了多智能体医疗 QA 框架中，不同模型（GPT、LLaMA、DeepSeek R1）承担不同角色（临床推理、证据检索、精炼），虽然整体准确率达 87%，但端到端延迟达 36.5 秒，且证据增强虽降低了困惑度（4.13），但未直接比较跨模型与同模型配置 [2]。[4] 指出，智能体 AI 面临的新挑战包括上下文管理、安全、隐私、信任以及多智能体协调问题 [4]；跨模型场景下，不同模型的架构差异、训练数据分布差异、推理风格差异可能加剧这些挑战。[3] 在群体智能基准测试中发现，当前 LLM 在分散化场景下的长程规划和自适应策略形成方面存在显著困难 [3]，这进一步支持了跨模型协调可能引入额外不确定性的观点。

## 3. 证据支持的研究方向

基于上述证据，以下研究方向具有理论依据和实证基础：

1. **信息效率量化研究**：借鉴 [5] 的信息论框架，设计实验量化跨模型 ARL 相对于同模型 ARL 的信息传递损失，例如通过比较不同模型组合在固定推理令牌预算下的任务完成度。
2. **上下文利用率对比**：研究不同模型（如 DeepSeek 与 Kimi）在作为审阅者时的上下文利用效率差异，验证 [5] 关于“单智能体上下文利用率下降时 MAS 才具竞争力”的预测。
3. **计算-性能权衡分析**：系统比较跨模型与同模型 ARL 在相同计算资源下的性能，排除 [5] 所指出的“未受控计算量增加”这一混淆因素。
4. **协调成本建模**：借鉴 [2][4] 的多智能体协调经验，建立跨模型 ARL 的协调成本模型，包括延迟、信息失真、角色冲突等维度。
5. **领域特异性验证**：在医疗 [2]、农业 [7]、遗传学 [8] 等专业领域验证上述理论预测，考察领域知识分布差异对跨模型协作的影响。

## 4. 摘要级证据的局限

本合成存在以下局限：

1. **直接证据稀缺**：目前尚无文献直接比较“跨模型 ARL（DeepSeek 写作 + Kimi 审阅）”与“同模型 ARL”的性能。核心理论框架 [5] 讨论的是 SAS vs MAS 的一般情况，未专门针对跨模型场景。
2. **摘要级信息不完整**：所有证据均来自摘要，缺乏方法细节（如具体模型版本、提示设计、任务难度控制），可能遗漏关键调节变量。
3. **领域偏差**：多数证据来自医疗 [2][8] 和通用推理 [3][5] 领域，对写作-审阅这一特定 ARL 任务的适用性需谨慎评估。
4. **时效性限制**：LLM 技术快速迭代，2025—2026 年的发现可能不适用于最新模型（如 DeepSeek 后续版本或 Kimi 更新）。
5. **风险偏倚**：[6] 的系统综述指出，当前 GenAI 用于证据合成的研究大多存在高或不明确的偏倚风险 [6]，本合成所依赖的预印本 [2][3][5] 尚未经过同行评审。

## 5. 谨慎结论

基于现有摘要级证据，跨模型 ARL（DeepSeek 写作 + Kimi 审阅）与同模型 ARL 的性能差距可从信息论角度得到初步理论解释：根据 [5] 提出的数据处理不等式视角，在固定推理令牌预算下，信息需在异构模型间传递的跨模型系统可能面临更高的信息效率损失；而同模型系统因上下文利用的一致性更高，理论上更接近信息最优。然而，这一解释依赖于“完美上下文利用”的理想假设，且缺乏直接针对写作-审阅任务的实证验证。现有证据 [2][3][4] 表明，多智能体系统的优势高度依赖于任务类型、计算预算和协调机制设计，跨模型配置可能在某些场景下通过模型互补性获得收益（如 [2] 中不同模型各司其职），但这一收益是否足以抵消信息传递损失尚不明确。建议未来研究在受控条件下（固定推理令牌、统一评估指标）直接比较跨模型与同模型 ARL 的性能，并探索模型选择、角色分配和通信协议对信息效率的影响。
