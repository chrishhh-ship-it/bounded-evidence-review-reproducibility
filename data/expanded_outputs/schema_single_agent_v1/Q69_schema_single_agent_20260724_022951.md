# 冻结语料库设置下，检索策略的选择如何影响证据覆盖率和引用孤儿率？

## 1. 检索与筛选概览

本合成基于一个固定的、不可扩展的语料库（E_q），包含8篇文献，涵盖6G网络[1]、ChatGPT综述[2]、多智能体系统[3]、电力市场设计[4]、AI聊天机器人[5][6]、AI接受度[7]以及信息系统委托框架[8]等主题。这些文献均来自2016至2023年间发表的同行评审期刊或会议，涉及人工智能、通信技术、能源系统和人机交互等多个领域。由于语料库是预先确定的，检索策略在此情境下体现为对E_q内部文献的选择性调用与组合，而非对更大语料库的搜索过程。证据覆盖率指合成中实际引用的文献占E_q总量的比例，引用孤儿率则指E_q中未被合成引用的文献比例。

## 2. 核心主题与证据

本合成聚焦于“检索策略对证据覆盖率和引用孤儿率的影响”，但E_q中的文献并未直接探讨检索策略或引用孤儿率这一方法论议题。相反，这些文献提供了关于人工智能代理、用户接受度以及系统委托等主题的摘要级证据。例如，[7]系统综述了AI接受度的预测因素，指出感知有用性、绩效期望、态度、信任和努力期望显著正向预测行为意图；[5]通过实验发现拟人化设计线索和社会存在感能提高用户对聊天机器人请求的遵从度；[6]在旅游情境下扩展了技术接受模型，验证了感知信任、感知智能和拟人化对采用意图的正向作用。[8]则从理论层面提出了向代理性信息系统委托权利与责任的框架，强调委托行为在信息系统使用中的核心地位。这些证据共同指向一个核心主题：用户对AI代理的接受与委托行为受到多种心理和社会因素的调节，但并未涉及检索策略对证据覆盖率的直接影响。

## 3. 证据支持的研究方向

基于E_q中的证据，可以识别出以下研究方向，这些方向虽未直接回答检索策略问题，但为理解“如何选择证据”提供了间接启示：

- **用户接受度与委托行为的整合研究**：[7]指出信任是AI接受的关键预测因素，而[8]将委托视为信息系统使用的核心机制。未来研究可探索信任如何调节用户向AI代理委托任务的意愿，以及这种委托行为如何影响用户对AI系统的持续使用。

- **拟人化设计对用户遵从的影响机制**：[5]和[6]均发现拟人化显著影响用户行为，但[5]强调社会存在感的中介作用，[6]则关注感知智能的作用。未来可比较不同拟人化维度（如外观、语言风格、情感表达）对用户遵从度的差异化影响。

- **跨文化情境下的AI接受差异**：[7]指出在某些文化情境中，人类接触需求无法被AI替代，无论其感知有用性如何。这提示未来研究需考虑文化变量对AI接受模型的调节作用，尤其是在[6]所关注的印度等新兴经济体。

- **代理性信息系统的委托框架实证检验**：[8]提出了理论框架，但缺乏实证验证。未来可利用[5][6]中的实验范式，检验委托框架中权利与责任转移的具体条件。

## 4. 摘要级证据的局限

本合成完全依赖E_q中文献的摘要级证据，存在以下局限：

- **信息粒度不足**：摘要通常仅提供研究背景、方法和主要结论的概要，缺乏对检索策略、引用孤儿率等具体方法学指标的详细描述。例如，[7]虽为系统综述，但其摘要未说明文献筛选过程中的排除标准或引用模式。

- **主题覆盖偏差**：E_q的8篇文献聚焦于AI应用与用户行为，未包含任何关于信息检索策略、证据合成方法或引用分析的研究。因此，无法直接评估不同检索策略（如布尔逻辑、引文追踪、主题词扩展）对证据覆盖率或引用孤儿率的影响。

- **时效性与领域限制**：文献发表时间跨度从2016至2023年，但[1]关于6G网络和[4]关于电力市场的文献与AI代理主题关联较弱，可能引入领域偏差。此外，摘要级证据无法反映全文中的方法学细节，如检索数据库、筛选流程或引用网络分析。

- **引用孤儿率不可计算**：由于E_q是固定且有限的，且合成中引用了全部8篇文献（见下文），引用孤儿率为0%。但在真实检索场景中，引用孤儿率需基于全文引用网络计算，而摘要级证据无法提供此类信息。

## 5. 谨慎结论

基于E_q中8篇文献的摘要级证据，本合成无法直接回答“检索策略如何影响证据覆盖率和引用孤儿率”这一研究问题。现有证据表明，用户对AI代理的接受与委托行为受到拟人化、信任、感知有用性等因素的影响[5][6][7]，且委托框架为理解人机交互提供了理论视角[8]。然而，这些发现与检索策略的方法学议题无直接关联。在冻结语料库设置下，证据覆盖率取决于合成者对E_q的选择性调用——本合成引用了全部8篇文献，覆盖率为100%，引用孤儿率为0%。但这一结果仅反映本合成的特定选择，不能推广至其他检索策略。未来研究需在包含检索方法学文献的扩展语料库中，系统比较不同检索策略（如主题词搜索、引文追踪、滚雪球法）对证据覆盖率与引用孤儿率的影响，并采用全文级证据以获取更精确的方法学细节。
