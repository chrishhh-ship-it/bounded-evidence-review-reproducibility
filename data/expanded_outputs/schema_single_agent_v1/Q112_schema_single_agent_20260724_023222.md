# 学术智能综合报告：LLM生成的历史文本主题摘要作为人文学科证据的引用规范

## 1. 检索与筛选概览

本报告基于提供的限定证据集E_q，共包含8条记录，涵盖数字人文、大型语言模型（LLM）应用、学术出版伦理及人文学科方法论等主题。证据来源包括学术期刊论文、预印本及会议文献，时间跨度为2016年至2025年。在检索过程中，重点关注与LLM生成内容在学术研究中的使用、引用规范及人文学科证据标准直接相关的文献。经筛选，[1]、[5]、[6]、[7]、[8]等记录与人文学科中LLM生成摘要的引用实践具有较高相关性，而[2]、[3]、[4]虽涉及数字人文或LLM应用，但未直接讨论引用规范问题。

## 2. 核心主题与证据

### 2.1 LLM生成内容的准确性与可靠性问题

多项证据表明，LLM生成内容的准确性存在显著局限。[5]明确指出ChatGPT“编译的信息并不总是准确的”，且其训练数据仅涵盖2021年及之前的信息，对于依赖最新进展的学术领域而言，这一信息缺口构成严重障碍[5]。此外，[5]引用的一项研究发现，医学研究者仅能正确识别68%由ChatGPT生成的摘要，表明AI生成内容具有高度迷惑性[5]。[6]和[7]进一步证实，在生物医学问答场景中，基于PubMed的检索增强系统仅能为约44%的问题提供有证据支持的答案，而结合新型证据源后这一比例提升至70%以上[6][7]。这些发现共同指向一个核心问题：LLM生成的摘要可能包含不准确或过时的信息，这对其作为人文学科证据的可靠性构成根本性挑战。

### 2.2 人文学科中证据标准的特殊性

[1]指出，人文学科与自然科学在方法论上存在根本差异：人文学科追求“理解”（verstehen）而非“解释”（erklären），其研究对象是“人类心智的表达”[1]。这一传统决定了人文学科对证据的要求不仅包括事实准确性，还涉及对历史语境、文化背景和诠释学意义的把握。[8]进一步论证，数字人文与人文学科的真正联系在于“扁平化文化技术”（cultural technique of flattening），即通过列表、表格、图表等空间化手段揭示文化制品中的潜在模式[8]。这意味着LLM生成的摘要若要作为人文学科证据，不仅需要确保事实正确，还需符合人文学科特有的诠释学传统。

### 2.3 学术出版中对AI生成内容的政策回应

面对LLM带来的挑战，学术出版界已开始制定相应政策。[5]报告指出，第40届国际机器学习大会已禁止使用AI工具（包括ChatGPT）撰写的论文，《科学》系列期刊也更新政策，明确不允许ChatGPT生成的文本[5]。[5]同时强调，ChatGPT“有趣，但不是作者”，AI工具应仅用于辅助性任务如校对和编辑[5]。这些政策动向为LLM生成摘要的引用规范提供了重要参照。

## 3. 证据支持的研究方向

基于现有证据，以下研究方向值得深入探索：

**方向一：LLM生成摘要的事实核查机制**。鉴于[5]、[6]、[7]反复强调LLM输出的不准确性，有必要开发专门针对人文学科文本的验证框架，确保LLM生成的历史文本主题摘要与原始文献一致。

**方向二：人文学科特有的证据评估标准**。[1]和[8]提示，人文学科的证据标准不能简单移植自自然科学。未来研究应探讨如何将诠释学方法、历史语境分析和“扁平化”技术纳入LLM生成内容的评估体系。

**方向三：引用透明度的规范制定**。[5]指出，学者难以检测同行是否使用了AI工具。因此，需要建立明确的披露规范，要求在使用LLM生成摘要时注明AI参与程度及所依据的原始文献范围。

**方向四：检索增强生成（RAG）技术在人文学科的应用**。[6]和[7]展示了RAG系统在生物医学领域提升证据支持率的潜力。类似方法可被引入人文学科，通过将LLM与经过验证的历史文本数据库对接，提高生成摘要的可信度。

## 4. 摘要级证据的局限

本报告所依据的摘要级证据存在若干固有局限。首先，摘要本身可能省略关键的方法论细节和限定条件。例如，[5]虽指出ChatGPT信息不准确，但未具体说明在历史文本分析场景中的错误类型和频率。其次，部分证据来自非人文学科领域：[4]讨论的是制药供应链管理，[6]和[7]聚焦生物医学问答，这些领域的发现能否直接推广至人文学科尚需验证。第三，[1]作为期刊创刊词，主要阐述学科愿景而非提供实证数据，其引用价值有限。第四，[2]的摘要信息不完整，无法确定其具体发现。最后，所有证据均为2025年及之前的文献，考虑到LLM技术的快速发展，部分结论可能已过时。

## 5. 谨慎结论

综合现有证据，当LLM生成的历史文本主题摘要被用作人文学科论证证据时，应遵循以下引用规范：

第一，必须对LLM生成内容进行独立事实核查。[5]和[6]的证据表明，LLM输出的准确性不可预设，研究者有责任验证摘要与原始历史文献的一致性。

第二，应明确披露LLM的使用情况。参照[5]提出的学术出版政策，在引用LLM生成摘要时，应注明AI工具的参与程度、训练数据截止日期及所依据的原始文本范围。

第三，引用应优先指向原始历史文献而非LLM生成的摘要。人文学科强调对原始文本的诠释学理解[1][8]，LLM摘要应仅作为辅助工具，而非替代直接引用。

第四，需建立人文学科特有的证据评估框架。鉴于[1]指出人文学科与自然科学的方法论差异，以及[8]强调的“扁平化”技术传统，LLM生成摘要的可靠性评估应纳入诠释学标准，而非仅依赖事实准确性检验。

第五，应关注LLM生成内容中的语言和权力偏见。[3]指出数字档案中殖民语言的主导地位可能延续历史不公，类似问题可能存在于LLM训练数据中，影响其对非西方历史文本的摘要质量。

总之，LLM生成摘要可作为人文学科研究的辅助工具，但尚不能替代经过同行评议的原始文献作为主要证据来源。随着检索增强生成技术的发展[6][7]，未来有望建立更可靠的LLM辅助引用体系，但当前阶段仍需保持谨慎。
