# 气候风险综合中避免低估尾部风险的引用实践：基于摘要级证据的分析

## 1. 检索与筛选概览

本合成基于提供的8条摘要级证据记录（E_q），这些记录涵盖气候风险、人工智能与文献综述方法、社会公平与适应等多个领域。证据来源包括2025年关于孟加拉国气候风险的综合研究[1]、2026年关于AI时代文献综述方法论的反思[2]、2020年关于AI在智慧城市中贡献与风险的系统综述[3]、2019年关于学习分析与AI政治学的综述[4]、2019年纽约市气候变化小组关于社区适应与公平的报告[5]、2025年关于金融稳定与气候风险的文献计量分析[6]、2025年关于气候智慧型花生生产的综合管理实践综述[7]，以及2024年关于气候变化与食物系统、营养、健康交叉的证据图谱[8]。这些记录的时间跨度为2019至2026年，涵盖不同学科视角，但均以摘要级信息呈现，未提供全文细节。

## 2. 核心主题与证据

现有摘要级证据揭示了若干可能影响气候风险综合中尾部风险认知的关键引用实践问题：

**（1）中位数情景的过度依赖风险**：多项证据表明，气候风险评估往往倾向于采用中位数或平均情景。例如，孟加拉国气候风险综合报告引用了“平均气温每十年上升0.16°C”和“2100年可能升高2.69°C”等中位数预测[1]，但未明确讨论极端情景或尾部风险的概率分布。类似地，关于金融稳定与气候风险的文献计量分析指出，研究主题集中于“宏观审慎政策、气候信息披露和环境风险整合”[6]，但未强调对极端系统性气候威胁的量化方法。

**（2）方法论选择对风险认知的塑造**：证据[2]强调，文献综述的学术价值在于“分析判断、基于证据的评估和严谨推理”，而非文本的简单呈现。然而，当前许多气候风险综述采用“主题性、案头式方法”并辅以“PRISMA式筛选过程”[1]，这种方法可能系统性地排除那些不符合主流范式的极端情景研究。证据[4]进一步指出，量化分析“在剥离背景信息时会丢失关键细节”，这直接关系到尾部风险——因其低概率、高影响特性，在标准化指标中容易被低估。

**（3）公平与脆弱性视角的缺失**：证据[5]详细阐述了分配公平、情境公平和程序公平三个维度，强调“结构性种族主义”等社会根源因素对脆弱性的影响。然而，证据[8]发现，在844份与气候-食物-营养-健康相关的综述中，仅25%“批判性地评估了公平性”，仅6%提出公平实践会改变气候-食物系统动态。这种公平视角的缺失可能导致风险综合低估了最脆弱群体面临的极端风险。

**（4）跨学科整合的不足**：证据[8]识别出四个关键研究空白，包括“研究整个食物系统或收获后要素”、“评估气候变化与营养健康结果之间的关系”、“识别干预杠杆点的方法”以及“通过跨学科合作进行证据转化”。证据[4]也指出，学习分析与AI领域“缺乏来自全球南方的作者和数据”，这种地域偏见同样存在于气候风险研究中——证据[1]虽聚焦孟加拉国，但未讨论如何将发展中国家特有的尾部风险纳入全球模型。

## 3. 证据支持的研究方向

基于上述分析，以下引用实践可能有助于避免气候风险综合中低估尾部风险：

**（1）明确报告极端情景与概率分布**：引用实践应要求综述不仅报告中位数预测，还需明确说明极端情景（如95%或99%分位数）及其概率权重。证据[1]虽提供了温度上升范围，但未系统讨论尾部事件的发生概率。证据[6]指出“对系统性气候威胁的担忧日益增加”，但未提供量化尾部风险的方法论指导。

**（2）纳入公平与脆弱性分析框架**：引用时应优先选择那些明确考虑分配公平、情境公平和程序公平的研究[5]。证据[8]的发现表明，当前综述普遍忽视公平维度，这可能导致风险综合低估了边缘化社区面临的极端风险。引用实践应要求综述至少说明其是否评估了不同社会群体的差异化风险暴露。

**（3）采用多方法、多证据源的综合策略**：证据[2]强调“基于证据的评估和严谨推理”，这意味着不应仅依赖单一模型或数据集。证据[7]展示了“综合作物管理组合”的方法，将遗传学、农学、土壤和水资源保护、病虫害管理等多方面证据整合，这种组合策略可类比于气候风险综合中整合物理风险、转型风险和情景分析。

**（4）明确披露方法论局限与地域偏见**：证据[4]揭示了AI教育研究中“全球北方主导”的问题，证据[3]也指出AI在智慧城市中的风险研究“有限”。引用实践应要求综述明确说明其证据的地理覆盖范围、方法论局限以及可能遗漏的尾部风险类型。

## 4. 摘要级证据的局限

本合成基于摘要级证据，存在以下固有局限：

**（1）信息粒度不足**：摘要通常仅提供研究的高层发现，无法获取方法细节、数据来源、敏感性分析等关键信息。例如，证据[1]提到“12篇文献被选中”，但未说明这些文献是否包含了极端情景研究。证据[5]虽详细描述了社会脆弱性指数，但摘要无法呈现其如何具体处理极端事件。

**（2）选择性报告偏差**：摘要倾向于突出正面或显著结果，可能忽略不显著或负面的尾部风险发现。证据[8]指出仅25%的综述评估了公平性，但摘要本身可能未充分反映这一比例背后的方法论选择。

**（3）时效性与覆盖范围**：证据集包含2019至2026年的文献，但气候风险研究领域发展迅速，2025年后的最新方法（如AI驱动的极端事件归因）可能未被充分覆盖。证据[3]和[4]虽讨论AI风险，但未直接涉及气候尾部风险的量化。

**（4）缺乏对引用实践的直接讨论**：本合成试图从现有证据中推断引用实践，但没有任何一条证据直接讨论“如何引用以避免低估尾部风险”。这一推论过程本身存在解释风险。

## 5. 谨慎结论

基于提供的摘要级证据，当前气候风险综合中的引用实践存在系统性低估尾部风险的倾向，主要表现为：过度依赖中位数情景预测[1]、忽视公平与脆弱性维度[5][8]、方法论选择导致极端情景被排除[2][4]、以及跨学科整合不足[8]。为缓解这一问题，引用实践应明确要求：报告极端情景及其概率分布、纳入公平分析框架、采用多方法综合策略、并披露方法论局限与地域偏见。

然而，这些结论完全基于摘要级证据，缺乏对全文引用实践的实证检验。摘要信息无法揭示作者在引用时是否实际考虑了尾部风险、是否进行了敏感性分析、或是否在讨论部分承认了极端情景的不确定性。因此，本合成应被视为一个初步框架，而非对实际引用实践的确定性描述。未来研究需要基于全文分析，系统评估气候风险综述中引用实践与尾部风险认知之间的因果关系。
