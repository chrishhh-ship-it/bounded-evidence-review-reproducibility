### 1. 检索与筛选概览

在数字人文学科的系统性文献综述中，处理软件工具作为主要研究贡献的引用问题，首先需要明确检索与筛选的策略。现有证据表明，系统性综述通常依赖多数据库检索，例如使用Scopus、PubMed、IEEE Xplore等，并结合人工与自动化工具进行筛选[1][4][8]。例如，一项关于在线厌女症的研究从Scopus数据库检索了1990年至2022年的2830篇文章[1]；另一项关于大语言模型（LLMs）辅助综述的研究则检索了PubMed、Scopus、Dimensions和Google Scholar，共获得3788篇文章，最终纳入172篇[4]。在筛选过程中，自动化工具如基于GPT-4o的Covidence插件被用于辅助筛选和提取[4]，而人工评审仍扮演关键角色[4][8]。这表明，软件工具在综述中既可作为研究对象，也可作为方法论工具，但其引用需遵循透明化原则。

### 2. 核心主题与证据

软件工具在数字人文学科综述中的核心角色体现在两个方面：一是作为研究贡献本身，二是作为综述流程的辅助手段。作为研究贡献，软件工具（如大语言模型、人工智能算法）被广泛用于分析数字文化现象，例如利用计算语言学方法研究在线厌女症[1]，或通过AI技术推动智慧城市发展[6]。这些工具不仅是技术载体，更是知识生产的核心要素，其引用应明确标注版本、架构及使用场景[4][6]。作为辅助手段，软件工具（如ChatGPT、Scite.ai）被用于文献检索、数据提取、代码生成和手稿撰写[4]，但其使用需谨慎，因为自动化提取在数值数据上准确性较低[4]。此外，证据显示，尽管LLMs在综述自动化中表现突出（如GPT模型在数据提取中平均精确率达83.0%），但仅有少数综述明确承认使用了LLMs[4]，这凸显了引用透明性的不足。

### 3. 证据支持的研究方向

基于现有证据，未来研究方向可聚焦于以下三点：第一，建立软件工具引用的标准化规范，包括工具名称、版本、算法架构（如GPT-4o或BERT）及使用阶段（如检索、提取）[4][6]。第二，探索软件工具在跨学科综述中的整合路径，例如将计算语言学方法与社会学分析结合，以应对复杂现象（如在线厌女症）[1][2]。第三，评估软件工具使用的伦理与隐私风险，尤其是在处理敏感数据时（如医疗或社会行为数据）[7][8]。此外，需加强软件工具在综述中的可重复性，例如通过公开代码和数据集[4][6]。

### 4. 摘要级证据的局限

本合成基于摘要级证据，存在以下局限：首先，摘要可能未充分反映软件工具的具体技术细节（如训练数据、参数设置）[4][6]，导致引用信息不完整。其次，部分摘要侧重于工具的应用效果而非方法论贡献，例如AI在智慧城市中的角色被概括为“技术应用”，但未深入讨论其作为研究贡献的引用标准[6]。此外，摘要级证据可能遗漏工具使用的负面结果或局限性，如LLMs在数值提取中的低准确性仅在部分摘要中提及[4]。最后，跨学科综述（如艺术与人文学科）的摘要往往强调社会影响而非技术细节[2]，这增加了软件工具引用的模糊性。

### 5. 谨慎结论

在数字人文学科的系统性文献综述中，软件工具作为主要研究贡献的引用应遵循透明、可重复和伦理合规原则。当前实践显示，工具的使用日益普遍，但引用规范尚不统一，需通过标准化指南（如明确工具版本、算法类型及使用阶段）来提升严谨性[4][6]。同时，研究者应警惕自动化工具的局限性（如数据提取误差）[4]，并优先采用混合方法（人工与自动化结合）以平衡效率与准确性[1][8]。未来，随着LLMs等工具的普及，综述方法论本身也需被纳入批判性审视[4][8]。
