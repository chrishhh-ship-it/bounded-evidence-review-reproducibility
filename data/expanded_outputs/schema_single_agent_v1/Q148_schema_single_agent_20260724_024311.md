# 数字人文语料库建设中边缘传统代表性不足问题的应对策略：基于摘要级证据的综合分析

## 1. 检索与筛选概览

本综合分析的证据基础来源于给定的八篇摘要级文献记录，涵盖数字人文、方法论反思、临床指南、气候变化适应等多个领域。在检索过程中，我们严格遵循了预设的证据集边界，仅使用编号为[1]至[8]的文献记录。由于这些文献并非针对数字人文语料库（DH corpus）建设这一特定主题的系统性检索结果，而是由外部提供的异质性证据集合，因此本分析本质上是一种探索性综合，旨在从跨学科视角提取可能适用于数字人文语料库建设的策略性启示。筛选标准为：文献摘要中是否包含与知识表征、方法选择、数据代表性或边缘群体相关的论述。

## 2. 核心主题与证据

### 2.1 系统性方法对多样性的潜在压制

文献[1]对系统性综述与叙事性综述的等级制提出了尖锐批评，指出“系统性”一词被错误地与高质量等同起来，而叙事性综述则被不公平地贬低。该文强调，系统性方法“倾向于将那些在严格定义的子集中具有共性的发现特权化”，从而“有可能显著扭曲我们的知识景观”[1]。这一论点对数字人文语料库建设具有直接启示：如果语料库建设过度依赖某种“系统性”的收录标准（如仅收录经过同行评议的经典文献或符合特定格式标准的数字化文本），则可能系统性地排除那些以非标准形式存在的边缘传统。

### 2.2 数字人文的跨文化挑战

文献[3]在讨论人文学科史时指出，西方术语和分类体系可能带来“欧洲中心主义的现时主义”（Eurocentric presentism）风险，即“用当前的概念和视角来解释过去和异域”[3]。该文特别提到，当西方方法被应用于非洲文学或中国艺术研究时，可能产生问题[3]。这一认识直接关系到数字人文语料库建设中如何处理非西方传统：如果语料库的元数据标准、分类体系和检索逻辑完全照搬西方数字人文实践，则非西方边缘传统可能因“不可通约性”而被排除或扭曲。

### 2.3 大规模语料库中的量化方法

文献[8]展示了一个基于3000年中国古代文献的大规模语料库分析案例，通过深度神经网络和图计算识别了数百万条互文关联[8]。该研究虽然主要关注文化演化，但其方法论启示在于：大规模语料库的构建本身就是一个选择性过程，研究者需要明确“个体学者与哲学流派之间的互动”以及“不同学派的兴衰”[8]。如果语料库仅收录被后世经典化的文本，则那些在历史长河中一度繁荣但后来衰落的边缘传统将无法被充分表征。

### 2.4 知识综合中的偏见问题

文献[1]进一步指出，系统性综述声称能减少偏见，但“偏见是一个流行病学概念，指的是扭曲群体间客观比较的东西”，而解释性研究必然是“视角性的”[1]。该文引用了一项挪威的研究，显示系统性综述所依据的证据基础“仅涉及相关政策问题的一小部分”[1]。这提示我们：数字人文语料库如果仅追求“客观”和“系统”的收录标准，反而可能因忽视边缘传统的独特价值而制造新的偏见。

## 3. 证据支持的研究方向

基于上述证据，以下研究方向可能有助于防止数字人文语料库过度表征经典作品而忽视边缘传统：

**方向一：采用多元方法论的语料库构建策略。** 文献[1]主张系统性综述与叙事性综述应被视为“不同且可能互补的学术形式”[1]。类似地，数字人文语料库建设不应仅依赖单一的系统性收录标准，而应结合专家判断、社区参与和解释性方法，确保边缘传统有被纳入的渠道。

**方向二：发展文化敏感的元数据框架。** 文献[3]强调使用“行动者范畴”（actors' categories）而非现代术语来描述历史实践，例如用“金石学”（jinshixue）而非“考古学”来描述中国十世纪的古物研究[3]。这一原则可应用于语料库建设：为不同文化传统的文献设计符合其自身学术传统的元数据标签，而非强行套用西方分类体系。

**方向三：量化分析与质性判断的平衡。** 文献[8]展示了量化方法在大规模语料库分析中的潜力，但其研究本身也依赖于对“互文关联”的理论界定。文献[1]则警告，过度依赖技术性综合方法可能导致“对思想性、深度、批判性反思过程的忽视”[1]。因此，语料库建设应在量化指标之外，引入专家评审和社区反馈机制来识别和收录边缘传统。

**方向四：关注“知识景观”的完整性。** 文献[1]指出，系统性方法可能“使我们忽视那些本应引起我们兴趣的奇妙多样性和变异”[1]。数字人文语料库建设应有意识地收录那些不符合主流范式的文本，包括地方性知识、口述传统、非正式出版物等，以维护知识生态的多样性。

## 4. 摘要级证据的局限

本分析基于摘要级证据，存在以下显著局限：

首先，证据集的异质性极高。八篇文献分属临床医学、人文学科史、农业推广、皮肤病学、人工智能、气候变化等不同领域，没有一篇直接讨论数字人文语料库建设中的代表性偏差问题。因此，本分析中的推论均属于跨领域类比，其适用性有待专门研究验证。

其次，摘要信息的深度有限。例如，文献[8]虽然涉及大规模语料库分析，但摘要未详细说明其语料库的收录标准和排除规则，无法判断其是否已经面临或解决了边缘传统代表性不足的问题。文献[3]讨论了人文学科史中的欧洲中心主义问题，但未涉及具体的语料库建设实践。

第三，缺乏实证数据支持。本分析未能提供任何关于数字人文语料库中经典作品与边缘传统实际比例的数据，也无法评估不同策略对改善代表性的量化效果。

## 5. 谨慎结论

基于现有摘要级证据，可以得出以下谨慎结论：

第一，数字人文语料库建设面临的方法论挑战与文献[1]所批评的“系统性综述优于叙事性综述”的等级制具有结构相似性。如果语料库建设者不加反思地采用单一的系统性收录标准，确实存在过度表征经典作品而忽视边缘传统的风险。

第二，文献[3]和[8]共同提示，跨文化语料库建设需要发展文化敏感的元数据体系和分类框架，避免西方中心主义的现时主义偏见。

第三，防止边缘传统被忽视的最有效策略可能是方法论多元化：在系统性收录标准之外，引入专家判断、社区参与和解释性方法，并建立定期评估语料库代表性偏差的机制。

然而，这些结论的强度受到证据集异质性和摘要信息深度的严重限制。要形成更具操作性的策略建议，需要针对数字人文语料库建设进行专门的系统性文献综述和实证研究。
