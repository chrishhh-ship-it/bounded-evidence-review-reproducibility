## 学术情报综合报告：IMRaD结构对文献综述报告的适用性及降低幻觉引用率的约束机制

### 1. 检索与筛选概览

本报告基于提供的8篇摘要级证据（E_q）进行综合。这些证据涵盖6G网络[1]、ChatGPT综述[2]、多智能体系统[3]、能源市场[4]、AI聊天机器人[5][6]、AI接受度系统综述[7]以及信息系统使用理论[8]等主题。由于E_q中无直接探讨“IMRaD结构”或“幻觉引用率”的文献，本报告将基于现有证据，从方法论、结构约束与引用可靠性角度进行推断性分析。

### 2. 核心主题与证据

**主题一：结构化综述方法的价值**  
现有证据表明，采用系统化、结构化方法的研究能有效提升综述质量。例如，[7]通过遵循PRISMA指南进行系统综述，从7912篇文章中筛选出60篇纳入分析，这种结构化流程有助于减少遗漏和偏差。类似地，[2]对ChatGPT进行了“全面综述”，涵盖背景、应用、挑战与未来方向，体现了结构化框架对综述完整性的保障。

**主题二：幻觉引用与信息可靠性风险**  
多篇证据指出AI技术（如ChatGPT）在生成内容时存在偏见、伦理问题及局限性[2]。[2]强调“尽管存在争议和伦理关切，ChatGPT在短时间内吸引了学术界、研究界和工业界的广泛关注”，这暗示了AI生成内容可能包含不准确或虚构的引用（即“幻觉”）。[5]和[6]则从用户合规性角度指出，AI聊天机器人常“未能满足客户期望”[5]，且技术焦虑（TXN）是用户采纳的重要障碍[6]，这些发现可类比至AI辅助写作中引用可信度的问题。

**主题三：结构约束对引用准确性的潜在影响**  
虽然E_q未直接研究IMRaD结构，但[7]的系统综述方法提供了启示：明确的纳入/排除标准（如要求论文同时关注“用户接受度”和“AI技术”[7]）可降低无关或错误引用的混入。此外，[8]提出的“委托框架”强调对信息系统（包括AI）的权责委托，这暗示在综述中明确界定引用来源的“委托”范围（如仅使用经过同行评审的文献）可能减少幻觉引用。

### 3. 证据支持的研究方向

基于现有证据，以下研究方向可能有助于降低文献综述中的幻觉引用率：

- **强化结构化筛选流程**：借鉴[7]的PRISMA方法，在IMRaD框架中嵌入严格的文献筛选标准（如来源类型、时间范围、方法学质量），可减少不可靠引用的混入。
- **引入人机协作验证机制**：[2]指出ChatGPT在研究中需“平衡AI辅助创新与人类专业知识”，[6]强调“人类旅行代理的粘性”对AI采纳的负面调节作用，这提示在综述中应保留人类对引用准确性的最终审核权。
- **明确引用来源的“委托”边界**：[8]的委托理论可应用于引用管理：研究者应明确“委托”给AI工具的任务（如文献检索）与保留给人类的任务（如事实核查），从而降低AI生成幻觉引用的风险。

### 4. 摘要级证据的局限

本报告基于的摘要级证据存在以下局限：
- **主题不匹配**：E_q中无直接探讨IMRaD结构或幻觉引用率的文献，所有推断均为间接关联，结论的可靠性受限。
- **摘要信息不完整**：摘要通常省略方法细节（如[3]的摘要仅提及“多智能体学习系统”的挑战，未说明具体结构），无法评估其内部结构对引用准确性的影响。
- **领域偏差**：E_q集中于AI、通信与能源领域，可能不适用于其他学科（如人文社科）的综述实践。

### 5. 谨慎结论

基于现有摘要级证据，可初步推断：IMRaD结构本身并非降低幻觉引用率的充分条件，但通过在其框架内嵌入系统化筛选流程（如PRISMA[7]）、人机协作验证机制[2][6]以及明确的引用委托边界[8]，可能有效减少不可靠引用的混入。然而，由于缺乏直接证据，上述结论需谨慎对待。未来研究应直接比较不同综述结构（包括IMRaD）下幻觉引用率的差异，并开发针对性的结构约束指标。
