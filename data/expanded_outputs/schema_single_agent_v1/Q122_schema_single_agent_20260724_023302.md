1. 检索与筛选概览

本合成所依据的证据集（E_q）包含8篇文献，涵盖多种综述类型与方法论讨论。其中，[4]对系统综述与叙事综述的层级关系进行了批判性反思，[8]探讨了扎根理论研究中文献回顾的时机问题，[6]则分析了大型语言模型（如ChatGPT）在医学文献检索与摘要中的应用潜力。其余文献[1][2][3][5][7]均为特定领域的综述研究，分别涉及旅游行程设计问题、数字厌女现象、工业4.0技术、城市绿化效果及低碳城市实验。这些文献的摘要级证据为回答“文献综述系统应如何处理档案检索工具与其所描述原始资料的引用关系”这一核心问题提供了间接但相关的视角。

2. 核心主题与证据

核心主题在于文献综述系统如何区分并恰当引用“元资料”（如档案检索工具）与“原始资料”。现有证据表明，综述方法论本身对此问题存在不同立场。[4]指出，系统综述强调方法透明与可重复性，倾向于优先引用经过严格筛选的原始研究，而叙事综述则更依赖专家判断，可能更灵活地引用包括检索工具在内的多种知识来源。这一分歧暗示，综述系统需根据其方法论定位来决定引用策略。[8]进一步揭示了在扎根理论研究中，关于何时进行文献回顾存在争议：Glaser主张延迟回顾以避免先入为主，而Strauss、Corbin及Charmaz等人则支持早期回顾。这一争论直接映射到“引用时机”问题：若系统在分析原始资料前先引用检索工具，可能影响理论生成的开放性；反之，若延迟引用，则可能降低检索过程的透明度。

此外，[6]提出了“检索-摘要-验证”范式，强调在利用AI辅助文献综述时，必须确保引用的可验证性。该文指出，ChatGPT等模型可能生成看似合理但实际虚构的引用，这警示综述系统在整合AI生成的摘要时，必须建立严格的引用验证机制，尤其要区分AI对原始资料的总结与对检索工具（如数据库）的描述。[1][2][3][5][7]作为具体领域的综述，其摘要均未明确区分对检索工具与原始资料的引用，这反映了当前综述实践中的普遍模糊性。

3. 证据支持的研究方向

基于上述证据，未来研究可沿以下方向展开：
- **方法论导向的引用规范研究**：借鉴[4]对综述类型的辨析，探索针对不同综述类型（系统综述、叙事综述、混合方法综述）制定差异化的引用规范，明确何时应引用检索工具（如说明检索策略），何时应直接引用原始资料（如支撑核心论点）。
- **AI辅助综述的引用可信度研究**：依据[6]的警示，开发用于检测和验证AI生成引用（尤其是对原始资料与检索工具的区分）的自动化工具，并研究如何将“检索-摘要-验证”范式嵌入综述系统，以降低“幻觉”风险。
- **扎根理论视角下的引用时机研究**：结合[8]的争论，实证检验在综述过程中不同引用时机（早期引用检索工具 vs. 延迟引用原始资料）对理论生成质量与综述结论的影响，为系统设计提供经验依据。
- **跨领域引用实践比较研究**：对比[1][2][3][5][7]等不同领域综述的引用模式，分析学科文化如何影响对检索工具与原始资料的引用偏好，从而为通用综述系统的设计提供情境化指导。

4. 摘要级证据的局限

本合成完全依赖摘要级证据，存在以下显著局限：首先，所有文献的摘要均未直接讨论“档案检索工具与原始资料的引用区分”这一具体问题，因此本合成只能基于间接推论，缺乏直接证据支撑。其次，[1][2][3][5][7]的摘要侧重于其综述发现，而非方法论细节，无法从中提取其实际引用策略的完整信息。再次，[4][6][8]虽涉及方法论，但其讨论背景（医学、教育、AI）与档案学领域存在差异，其结论的迁移性需谨慎评估。最后，摘要可能省略了关键的方法论细节（如是否明确区分了检索工具与原始资料的引用），导致分析深度受限。

5. 谨慎结论

基于现有摘要级证据，可以谨慎推断：文献综述系统在处理引用时，应首先明确其方法论立场（如[4]所述的系统性与叙事性之分），并据此制定引用策略。对于强调方法透明度的系统综述，应优先引用原始资料，同时将检索工具（如数据库、档案目录）作为方法部分的可追溯证据；对于强调理论建构的叙事综述，则可更灵活地引用检索工具以说明知识来源。此外，鉴于[6]揭示的AI引用不可靠性，任何综述系统在整合AI生成内容时，必须强制实施引用验证步骤。最后，[8]关于引用时机的讨论提示，系统设计应允许用户根据研究阶段（探索期 vs. 验证期）动态调整对检索工具与原始资料的引用优先级。然而，这些结论高度依赖间接推理，亟需针对档案学领域的直接实证研究加以验证。
