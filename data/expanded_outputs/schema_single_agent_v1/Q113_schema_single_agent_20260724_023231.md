1. 检索与筛选概览

本合成基于所提供的八项摘要级证据，这些证据涵盖了不同的研究方法论，包括叙事综述、系统综述、以及关于人工智能工具（如ChatGPT）在学术研究中应用的评论。证据来源包括医学教育、临床心理学、环境健康、社会科学等多个领域，发表时间从2018年至2025年。检索与筛选过程遵循了预设的边界，仅使用给定的证据集（E_q），未引入外部文献。这些证据共同构成了探讨“主题建模输出与叙事框架分析差异”以及“何时在数字人文学（DH）论文中引用何种证据”这一研究问题的知识基础。

2. 核心主题与证据

核心主题在于区分两种不同的知识综合范式：系统综述与叙事综述，并探讨其各自的适用场景与证据价值。

首先，系统综述与叙事综述在认识论和方法论上存在根本差异。系统综述通常基于实证主义和后实证主义世界观，旨在通过预设的、可重复的方法，对特定、狭窄的研究问题进行穷尽式检索和量化综合，其核心是产生可概括的“事实”以辅助预测[1][4]。例如，一项关于城市绿化效果的系统综述通过元分析量化了绿化对温度的降低效应[7]。相比之下，叙事综述则根植于主观主义和解释主义范式，其目标是提供一种基于专家判断和批判性解读的“合理真理”，通过有目的的文献选择和解释性综合，产生对复杂、广泛主题的深刻理解[1][4]。叙事综述承认作者的视角会塑造分析结果，因此其结论具有情境依赖性[1]。

其次，两种范式各有其独特的优势与局限。系统综述的优势在于其方法透明、可审计，能有效减少特定类型的偏倚，尤其适用于回答“何种干预措施对特定人群有效”这类聚焦问题[4]。然而，其局限性在于可能因过度强调方法流程而忽视了对文献隐含假设和讨论的批判性分析，甚至可能因排除了大量异质性研究而扭曲知识图景[4]。叙事综述的优势在于其灵活性和实用性，能够整合多种类型的知识，提供丰富的、有洞察力的概述，并指出未来研究方向[1][4]。但其常被批评为可能“挑选”证据以支持特定观点[4]。值得注意的是，高质量叙事综述并非“非系统化”的，它同样遵循严谨的框架，包括明确研究问题、界定范围、解释检索策略、阐明分析过程以及反思作者视角[1]。

最后，关于何时引用何种证据，证据表明这取决于研究问题的性质。对于需要澄清和洞察的“谜题”，叙事综述更为合适；而对于需要数据回答的“问题”，系统综述（必要时结合元分析）是首选方法[4]。在数字人文学（DH）中，若研究旨在探索文本中隐含的、多义的叙事框架或主题演变，叙事综述（如元叙事综述）能够提供更深刻的解释性理解[4]。相反，若研究旨在量化特定主题在语料库中的分布频率或验证预设的假设，则系统综述的方法论更为严谨。此外，关于ChatGPT等AI工具的讨论提醒我们，在引用任何形式的证据时，都必须警惕信息不准确或“幻觉”的风险，并坚持核实来源[5][8]。

3. 证据支持的研究方向

基于现有证据，未来研究可从以下几个方向展开：

- **方法论比较研究**：开展实证研究，直接比较在数字人文学（DH）语境下，使用主题建模（一种计算方法）与叙事框架分析（一种定性方法）对同一文本语料进行分析时，其输出结果在深度、广度、可解释性及偏倚风险上的具体差异。这有助于建立更精细的证据引用指南。
- **混合方法设计**：探索如何将系统综述的严谨检索与叙事综述的深度解释相结合，例如在DH研究中，先通过系统方法构建一个全面的文献库，再运用叙事框架分析对关键文本进行解读，以克服单一方法的局限[4]。
- **AI辅助综述的可靠性研究**：鉴于ChatGPT等工具在总结和生成文本方面的潜力与风险[5][8]，未来应研究如何利用这些工具辅助文献筛选或初步综合，同时开发自动验证工具以确保其输出的准确性和完整性，从而提升综述的效率与质量。
- **跨学科证据整合**：借鉴叙事综述能够整合多种知识来源的优势[1]，在DH研究中探索如何系统性地融合来自计算科学、社会学、历史学等不同学科的证据，以应对复杂的人文研究问题。

4. 摘要级证据的局限

本合成完全依赖于摘要级证据，这带来了若干固有局限。首先，摘要通常仅提供研究的高层概述，缺乏对方法细节、数据分析过程及完整讨论的深入描述。例如，关于叙事综述的讨论[1][4]虽然指出了其与系统综述的差异，但未提供具体的操作步骤或案例分析，限制了对其方法论细节的理解。其次，摘要可能无法充分反映研究的局限性或潜在的偏倚风险。例如，关于ChatGPT的评论[5][8]指出了其“幻觉”问题，但摘要中并未详细说明在何种具体任务或提示下该问题最为突出。最后，摘要级证据的概括性可能导致对复杂概念的简化，例如“主题建模”与“叙事框架分析”的具体操作差异在提供的摘要中并未被直接讨论，需要依赖读者对相关领域的先验知识进行推断。因此，本合成的结论应被视为基于有限信息的初步探索，而非最终定论。

5. 谨慎结论

综上所述，主题建模输出与叙事框架分析代表了两种不同的知识生产范式：前者倾向于数据驱动的、可量化的模式发现，后者则侧重于解释性的、情境化的意义建构。在数字人文学（DH）论文中引用证据时，不应简单地将系统综述置于叙事综述之上，而应根据研究问题的性质做出选择[4]。对于旨在探索意义、叙事和复杂语境的研究，叙事综述（包括其多种子类型）是恰当且严谨的证据形式[1][4]；而对于旨在检验假设、量化效应或进行可重复综合的研究，系统综述则更为合适[2][7]。研究者应警惕任何形式的“证据等级”偏见，并认识到高质量的综述，无论其类型，都依赖于透明的方法和批判性思维[4]。同时，随着AI工具的发展，对任何来源的证据进行核实与批判性评估变得比以往任何时候都更为重要[5][8]。最终，明智的证据引用应基于对方法论优缺点的深刻理解，并与具体的研究目标相匹配。
