## 1. 检索与筛选概览

本合成基于提供的八篇摘要级证据记录，涵盖证据合成方法学、大型语言模型（LLM）应用、以及特定领域的证据综合实践。这些文献发表于2020至2026年间，来源包括医学、社会科学、计算机科学及证据综合专业期刊。筛选过程遵循预设的检索边界，仅使用E_q集合中的记录，未引入外部文献。

## 2. 核心主题与证据

证据合成领域面临多重挑战与机遇。在方法学层面，GRADE等工具在应用于复杂干预和人群时存在困难，且部分偏倚风险评估工具（如Cochrane RoB 2和ROBINS-I）因过于复杂而导致误用和可靠性不足[6]。同时，证据合成需要适应不同学科的需求：在气候变化领域，定性证据综合方法的应用不足，且缺乏对情境和中介因素的系统考量[3]；在医学领域，真实世界证据（RWE）的教学需要结合建构主义和体验式学习，但面临教育者信念和组织障碍[8]。

大型语言模型（LLM）在证据合成中展现出潜力与局限。ChatGPT等模型能够生成流畅的摘要，但存在“幻觉”问题，即产生看似可信但实际虚构的回应，且无法可靠地引用来源[1]。检索增强型LLM虽能减少幻觉，但可能限制用户对来源的控制，导致结果不全面或遗漏重要证据[1]。在游戏开发中，LLM可用于非玩家角色（NPC）的对话管理，但其在证据合成中的直接应用仍需谨慎[4]。

## 3. 证据支持的研究方向

基于现有证据，以下研究方向值得关注：第一，发展自动化工具和计算机辅助方法，以应对大规模文献的筛选和综合需求[3][5]。第二，改进定性证据综合和混合方法综合的方法学，特别是在气候变化和社会科学领域[3]。第三，探索LLM与检索系统结合的“检索-总结-验证”范式，以平衡LLM的总结能力与证据可靠性[1]。第四，加强证据综合培训，包括通过微任务平台（如Cochrane Crowd）提高筛选效率和准确性[5]，以及针对RWE的教学方法创新[8]。

## 4. 摘要级证据的局限

本合成完全依赖摘要级证据，存在以下固有局限：首先，摘要可能无法完整反映研究的详细方法、结果和局限性，例如对GRADE工具复杂性的批评[6]需要全文验证。其次，部分记录为预印本或早期研究[2][4][8]，其结论可能尚未经过同行评议的充分检验。第三，摘要中关于LLM“幻觉”的描述[1]缺乏具体实验数据和量化指标，限制了结论的精确性。最后，不同研究在方法学质量、样本量和研究设计上存在差异，摘要无法提供充分的偏倚风险评估信息。

## 5. 谨慎结论

现有证据表明，证据合成方法学正处于快速发展与自我反思的阶段。一方面，传统工具（如GRADE）和新兴技术（如LLM）都在寻求更有效的应用方式；另一方面，方法学的复杂性、跨学科适应性以及证据可靠性仍是核心挑战。对于LLM在证据合成中的应用，应坚持“检索-总结-验证”的审慎范式[1]，避免直接依赖模型输出。未来研究需要更系统地评估自动化工具的有效性，并发展适用于不同学科背景的混合方法综合框架。所有结论均受限于摘要级证据的固有局限，需在全文验证后进一步确认。
