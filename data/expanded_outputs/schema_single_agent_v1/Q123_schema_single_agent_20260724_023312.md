# 数字人文学科中众包转录项目可重复性要求：基于摘要级证据的学术情报合成

## 1. 检索与筛选概览

本合成基于提供的限定证据集E_q，共包含8篇文献记录。这些文献涵盖临床医学指南（如皮肤鳞状细胞癌管理[1]、儿童慢性功能性便秘[2]）、公共卫生干预（如家长与儿童体重沟通指导[3]）、人工智能在学术研究中的应用（如GPT用于文献筛选[4]及学术出版[5]）、气候变化政策工具[6]、数字人文学科中历史报纸数字化使用[7]以及儿童慢性疼痛心理干预[8]。然而，直接针对“数字人文学科（DH）众包转录项目可重复性要求”这一研究问题的文献在证据集中缺失。现有证据主要来自医学、公共卫生和人工智能领域，与DH研究方法的直接关联性有限。因此，本合成将采用类比推理和跨学科映射的方式，从这些间接相关证据中提取可能适用于DH众包转录项目的可重复性要素。

## 2. 核心主题与证据

**2.1 系统化方法与透明报告的重要性**

多个证据来源强调了系统化方法和透明报告在确保研究可重复性中的核心作用。在临床指南制定中，英国皮肤病学家协会（BAD）的指南开发采用了AGREE II工具和GRADE方法，明确记录了系统文献检索策略、数据提取、质量评价和证据综合的完整流程[1]。类似地，儿童慢性功能性便秘的SUCCESS证据综合项目详细描述了其混合方法综述的设计，包括双重审稿人应用纳入标准、评估偏倚风险、以及由第二位审稿人核对数据提取[2]。这些实践表明，明确记录研究流程的每一步骤是可重复性的基础。

**2.2 数据来源与工具的可追溯性**

可重复性要求研究过程中使用的数据来源和工具具有可追溯性。在气候变化政策工具的开发中，研究者系统检索了IPCC第六次评估报告、Web of Science和Lancet Countdown报告中的同行评审文献，并明确记录了纳入标准和数据分析过程[6]。对于DH众包转录项目而言，这意味着需要详细记录原始文献的来源、数字化过程、转录平台的选择、众包志愿者的培训与监督机制，以及质量控制流程。

**2.3 人工智能工具使用的伦理与透明度**

随着AI工具在学术研究中的普及，其使用方式直接影响研究的可重复性。关于ChatGPT在学术研究中的应用评论指出，AI生成内容可能包含不准确或过时的信息，且人类审稿人难以完全识别AI生成的文本[5]。该评论强调，使用AI工具进行编辑和校对等辅助性工作是可行的，但涉及专业知识或创新性见解的任务仍需人类主导[5]。此外，GPT用于文献标题和摘要筛选的研究显示，虽然GPT-4模型在特定阈值下可实现100%的召回率，但研究者仍警告需要更多测试和方法论开发来评估LLM在筛选中的严谨性和有效性[4]。这些发现提示，DH众包转录项目若使用AI辅助转录或质量控制，必须明确记录AI工具的使用范围、版本、参数设置及人工审核流程。

**2.4 用户交互与工作流程的文档化**

数字历史报纸作为一手资料的使用研究表明，历史学者与数字化资料的交互涉及任务规划、搜索过程、选择与处理文献、综合与报告等多个活动阶段，每个阶段都需要不同的系统支持机制[7]。这一发现对众包转录项目具有直接启示：项目的可重复性不仅取决于最终转录数据的质量，还取决于对用户（包括研究者和众包参与者）与系统交互过程的完整记录，包括搜索策略、选择标准、数据提取方法和分析流程。

**2.5 多学科协作与方法的融合**

证据显示，历史研究领域正在经历向自然科学文化趋同的转变，定量方法和多学科协作正在塑造新的研究文化[7]。这一趋势对DH众包转录项目的可重复性提出了更高要求：项目需要明确记录所采用的方法论框架、跨学科协作的具体安排、以及不同学科标准之间的协调机制。

## 3. 证据支持的研究方向

基于上述证据分析，以下研究方向可能有助于建立DH众包转录项目的可重复性标准：

**3.1 开发DH特有的可重复性检查清单**

借鉴临床指南中的AGREE II工具和GRADE方法[1]，以及SUCCESS项目中的系统综述方法[2]，可以开发针对DH众包转录项目的可重复性检查清单。该清单应涵盖：项目设计文档化、数据来源与数字化流程、众包平台选择与配置、志愿者招募与培训、质量控制机制、转录后验证流程、以及数据分析方法的完整记录。

**3.2 建立AI辅助转录的透明度标准**

鉴于AI工具在学术研究中的广泛应用及其潜在风险[4][5]，需要为DH众包转录项目中使用的AI辅助工具建立透明度标准。这包括：明确记录AI工具的名称、版本、训练数据范围、使用场景（如自动转录、质量检查、文本校正等）、人工审核比例和流程、以及AI输出错误的处理机制。

**3.3 探索用户交互数据的系统化记录**

数字历史报纸使用研究揭示了用户交互的多阶段特性[7]，这提示众包转录项目需要系统化记录用户（包括研究者和志愿者）的交互数据，包括搜索行为、选择偏好、编辑历史、反馈机制等。这些数据不仅有助于理解转录过程，也是评估项目可重复性的重要依据。

**3.4 推动跨学科方法论框架的整合**

历史研究向自然科学文化趋同的趋势[7]表明，DH众包转录项目需要整合来自不同学科的方法论标准。这包括：借鉴医学研究中的系统综述方法[1][2]、公共卫生干预中的利益相关者参与机制[3]、以及环境科学中的证据综合工具[6]，形成适用于DH领域的综合性可重复性框架。

## 4. 摘要级证据的局限

本合成基于摘要级证据，存在以下显著局限：

**4.1 直接相关性不足**

证据集中没有任何文献直接讨论数字人文学科众包转录项目的可重复性要求。现有证据主要来自医学、公共卫生和人工智能领域，与DH研究方法的直接关联需要通过类比推理建立，这增加了推断的不确定性。

**4.2 摘要信息的深度限制**

摘要级证据仅提供研究的高层概述，缺乏方法细节和具体发现。例如，关于GPT用于文献筛选的研究[4]仅报告了召回率和时间节省比例，但未提供关于提示词设计、模型参数调整、以及不同数据类型下性能差异的详细信息。同样，关于数字历史报纸使用的研究[7]仅描述了交互活动的类型，但未提供具体的交互模式或系统设计建议。

**4.3 时间与领域偏差**

证据集中部分文献发表于2020-2025年期间，但AI相关文献[5]明确指出ChatGPT的训练数据仅更新至2021年，存在信息滞后问题[5]。此外，医学领域的证据[1][2][8]可能过度强调随机对照试验和系统综述的方法论标准，这些标准在DH领域可能不完全适用或需要调整。

**4.4 缺乏DH领域的实证研究**

证据集中没有包含任何关于DH众包转录项目的方法论研究或案例报告。这意味着本合成无法基于DH领域的直接实证证据来评估可重复性要求，只能依赖跨领域类比和理论推断。

## 5. 谨慎结论

基于现有摘要级证据，可以得出以下谨慎结论：

第一，DH众包转录项目的可重复性要求应借鉴医学和公共卫生领域已建立的系统化方法，包括明确记录研究设计、数据来源、分析流程和质量控制机制[1][2]。这些实践为建立DH特有的可重复性标准提供了方法论基础。

第二，AI工具的使用在DH众包转录项目中可能带来效率提升，但也引入新的可重复性挑战。必须建立AI使用的透明度标准，包括明确记录工具版本、使用范围、人工审核流程和错误处理机制[4][5]。

第三，用户交互数据的系统化记录是评估项目可重复性的重要维度。借鉴数字历史报纸使用研究[7]的发现，众包转录项目需要记录从任务规划到最终合成的完整交互过程。

第四，跨学科方法论框架的整合是DH众包转录项目可重复性的关键。需要将医学研究中的证据综合方法[1][2]、公共卫生中的利益相关者参与机制[3]、环境科学中的决策支持工具[6]与DH领域特有的数字化和众包实践相结合。

然而，必须强调，这些结论主要基于间接证据和类比推理。要建立DH众包转录项目的具体可重复性要求，还需要开展针对性的实证研究，包括对现有DH众包项目的系统回顾、方法论框架的开发和验证、以及跨学科标准的协调与整合。在获得更直接的证据之前，本合成提出的可重复性要素应被视为初步建议，而非既定标准。
