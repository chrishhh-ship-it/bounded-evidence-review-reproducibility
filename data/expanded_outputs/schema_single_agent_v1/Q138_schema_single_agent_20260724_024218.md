# 中文智能综合报告：数字人文学科基准测试中“地面真相”争议问题的处理

## 1. 检索与筛选概览

本报告基于提供的8条摘要级证据记录，围绕“数字人文学科（DH）基准测试应如何应对人文学科解释中‘地面真相’（ground truth）固有争议性”这一研究问题展开综合。在筛选过程中，排除了与DH方法论或基准测试无直接关联的记录，例如[2]关于城市绿化对臭氧和热岛效应影响的系统综述，以及[5]关于ChatGPT在临床与转化医学中应用的评论。最终，[1]、[3]、[4]、[6]、[7]、[8]被确认为核心相关证据，涵盖了DH的认识论基础、生成式AI的采用、基准测试设计原则、建构主义与统计方法的张力、人文学科研究影响评估以及DH课程开发等维度。

## 2. 核心主题与证据

### 2.1 “地面真相”争议的认识论根源

人文学科中“地面真相”的争议性根植于其建构主义认识论传统。[6]指出，建构主义原则在DH学术中虽常隐而不彰，却是基础性的；随着统计方法（尤其是贝叶斯方法）的引入，认识论张力随之产生。[6]进一步论证，贝叶斯统计与建构主义之间存在“干扰”（interferences），这揭示了认识论假设如何塑造知识生产。同时，[1]提出DH与古典人文学科的真正联系在于“扁平化文化技术”（cultural technique of flattening），而非诠释学；计算方法的量化操作如同“计算机生成的显微镜和望远镜”，能够揭示文化人工制品中潜在和隐性的模式，这些模式通常不为人类感知所及。这意味着，DH基准测试所依赖的“地面真相”并非客观给定的，而是通过特定认识论框架建构和“扁平化”后的产物。

### 2.2 基准测试设计中的争议处理原则

[4]提出了深度研究基准测试的四项核心原则：任务应（1）以用户为中心、（2）动态且需要最新信息、（3）无歧义以确保一致解释、（4）多层面且搜索密集。其中，“无歧义”原则与“地面真相”争议直接相关——[4]强调任务应确保不同用户之间的一致解释，这暗示基准测试需要明确界定何为“正确”答案。然而，[7]指出，人文学科研究的影响评估本身就缺乏共识，部分学者甚至质疑“影响”概念是否适用于捕捉人文学科研究对社会的意义。这提示，在DH基准测试中，对“地面真相”的界定不能简单移植STEM领域的客观标准，而需考虑人文学科知识生产的特殊性。

### 2.3 技术采用中的认识论张力

[3]调查了DH学者对生成式AI的采用情况，发现学界存在分歧：一方面承认GenAI能提升研究效率并促进技能重塑，另一方面担忧其可能扰乱学者的“智力身份”（intellectual identities）。[3]通过行动者网络理论（ANT）视角指出，GenAI的采用正在逐渐改变该领域，但这种转变仍充满争议，受制于多个人类与非人类行动者之间的持续协商。这种争议性直接映射到基准测试中——如果DH学者对技术工具的认识论角色尚无共识，那么基准测试所依据的“标准答案”也难以获得普遍认可。

### 2.4 跨学科课程中的认识论整合

[8]基于在新加坡向计算机科学家教授DH的经验，强调需要更好地阐明和理论化人文学科与计算机科学认识论之间的联系。[8]指出，DH要超越传统人文学科系所的范围，就必须更开放地参与可能不认同DH学科身份的计算文化研究。这暗示，DH基准测试的设计不能仅从单一学科视角出发，而应容纳多元认识论立场，从而在“地面真相”问题上保持必要的灵活性。

## 3. 证据支持的研究方向

基于上述证据，以下研究方向值得关注：

**方向一：建构主义导向的基准测试方法论**。借鉴[6]对贝叶斯统计与建构主义张力的分析，以及[1]对“扁平化”作为DH方法论基础的论证，可探索将概率性、多值或区间性答案纳入基准测试，而非追求单一“正确”答案。例如，采用贝叶斯先验分布来表征不同解释路径的合理性，从而在基准测试中容纳解释的多元性。

**方向二：动态与情境化的基准测试设计**。[4]提出的“动态”原则（需要最新信息）和“以用户为中心”原则，可与人文学科解释的语境依赖性相结合。基准测试任务可设计为要求系统根据特定理论框架或文化语境生成解释，而非追求跨语境的普适性“真相”。

**方向三：认识论透明性评估**。[3]揭示的学者对技术工具“智力身份”影响的担忧，以及[7]指出的人文学科影响评估的争议性，提示基准测试应纳入对系统认识论立场的评估。例如，要求系统明确声明其解释所依据的理论假设、数据选择标准和推理路径，从而让“地面真相”的建构过程透明化。

**方向四：跨学科共识建构机制**。[8]强调的认识论整合需求，以及[3]中行动者网络理论视角下的持续协商过程，建议基准测试的设计应通过多方利益相关者（人文学者、计算机科学家、图书馆员等）的参与式流程来共同界定“可接受的解释范围”，而非由单一群体预先设定。

## 4. 摘要级证据的局限

本报告所依据的摘要级证据存在以下局限：

**第一，证据覆盖范围有限**。核心证据[1]、[3]、[6]、[8]虽涉及DH认识论和方法论，但均未直接讨论“基准测试”或“地面真相”问题。例如，[1]聚焦于“扁平化”技术而非基准测试设计；[6]探讨贝叶斯统计与建构主义的理论关系，未涉及具体评估实践。因此，本报告的推论具有间接性和推测性。

**第二，证据类型单一**。所有证据均为摘要级文本，缺乏对具体基准测试案例、实证研究或实践指南的详细描述。[4]虽直接涉及基准测试，但其关注点是“深度研究”系统而非DH特有的解释争议问题。此外，[2]和[5]因主题不相关而被排除，进一步缩小了可用证据范围。

**第三，时间与地域偏差**。证据主要来自2022-2025年，且[8]明确基于新加坡语境，[3]的调查对象可能以欧美学者为主。这种时空局限性可能影响结论的普适性，尤其是考虑到DH在全球不同地区的发展路径和认识论传统存在显著差异。

**第四，缺乏对“争议性”的操作化定义**。现有证据虽承认人文学科解释的争议性，但未提供如何将这种争议性转化为可测量、可评估的基准测试指标的具体方案。这导致本报告的建议停留在原则层面，难以直接指导实践。

## 5. 谨慎结论

综合现有摘要级证据，可以得出以下谨慎结论：

（1）DH基准测试必须正视“地面真相”的建构性本质，而非将其视为客观给定的标准。[1]和[6]共同表明，DH的知识生产依赖于特定的认识论框架和“扁平化”操作，这意味着基准测试的“正确答案”本身就是特定认识论立场的产物。

（2）基准测试设计应采纳多元认识论视角，通过概率性、情境化和透明化的评估机制来容纳解释的争议性。[4]提出的“无歧义”原则需要结合DH的特殊性进行重新诠释——无歧义不应等同于单一答案，而应确保评估标准对不同认识论立场的一致性适用。

（3）技术工具的采用加剧了而非解决了“地面真相”争议。[3]揭示的学者对GenAI的复杂态度，以及[5]指出的AI生成内容准确性风险，提示基准测试需要区分“人类解释”与“机器生成解释”的不同认识论地位，避免将技术中介的产物误认为“客观真相”。

（4）跨学科共识的建构是基准测试有效性的前提。[7]和[8]共同强调，人文学科研究的影响评估和课程设计都需要跨学科对话；同理，DH基准测试的成功依赖于计算机科学家、人文学者和领域专家之间就“何为有效解释”达成最低限度的共识。

（5）当前证据不足以支持制定具体的基准测试方案。本报告提出的研究方向（如贝叶斯概率答案、认识论透明性评估）仍需通过实证研究验证其可行性。建议未来研究在[4]的基准测试框架基础上，结合[6]的建构主义-贝叶斯理论视角，设计小规模试点实验，探索如何在DH特定任务（如文本解释、文化模式识别）中操作化“争议性地面真相”。
