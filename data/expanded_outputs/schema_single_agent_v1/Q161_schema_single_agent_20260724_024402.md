# 自动化综述管线中全文本阅读资格筛选的应对策略：基于摘要级证据的合成分析

## 1. 检索与筛选概览

本合成基于提供的8篇文献证据集，聚焦于自动化综述管线在处理需要全文本阅读的资格筛选标准时，面对多数语料仅有摘要可用的困境。纳入文献涵盖范围综述方法论[1]、机器学习在医学领域的应用综述[2]、ChatGPT在全文筛选中可靠性的实证评估[3]、系统综述更新实践[4]、大语言模型在医学文献检索中的应用[5]、ChatGPT在学术研究中的影响[6]、生成式AI对语言教育的影响[7]以及证据合成术语分类的范围综述[8]。这些文献共同构成了从方法论基础到技术实现的多层次证据基础。

## 2. 核心主题与证据

**2.1 全文本阅读在综述流程中的必要性**

范围综述的方法论要求明确指出，对于纳入的文献，评审者需要“阅读每篇论文的全文，以识别要纳入数据提取表的文本片段”[1]。这一要求源于综述流程中资格筛选和数据提取两个关键阶段都需要全文本信息。在机器学习应用于输血医学的范围综述中，研究者实际执行了全文审查流程：在标题和摘要筛选后，对93篇文章进行了全文审查，并因全文不可用而排除了2项研究[2]。这表明全文本阅读是综述流程中不可回避的环节。

**2.2 自动化工具在全文筛选中的潜力与局限**

针对ChatGPT在系统综述全文筛选中可靠性的实证研究提供了关键证据。该研究评估了自定义GPT（cGPT）在全文筛选中的表现，发现cGPT作为“第二评审者助手”角色时，其与共识决策的kappa值为0.733（95% CI: 0.607, 0.859），落入了人类评审者之间kappa值范围（0.713-0.784）的置信区间内，达到了实际使用的阈值[3]。然而，cGPT作为自主评审者或第一评审者助手时未能达到可靠性阈值[3]。该研究还估计，使用cGPT进行全文筛选可节省10.1至84.4小时[3]。

**2.3 大语言模型在文献处理中的能力边界**

大语言模型在医学文献信息检索中的应用研究表明，ChatGPT存在“生成自信但虚构回应”的倾向，即“幻觉”问题[5]。尽管ChatGPT在文本摘要方面表现出潜力，但其生成的摘要可能遗漏重要观点或包含输入来源不支持的主张[5]。另一项评论指出，ChatGPT最显著的缺点是“其汇编的信息并不总是准确的”，且其数据仅涵盖2021年及之前的信息[6]。这些局限性直接影响了自动化工具在需要精确判断的资格筛选任务中的可靠性。

**2.4 摘要级证据与全文本证据的信息差距**

在范围综述中，资格标准可能在“筛选摘要和全文论文的过程中被细化”[1]，这暗示了摘要级信息与全文本信息之间存在实质性差异。机器学习在输血医学综述的筛选过程中，有16项研究在全文审查阶段被排除，原因包括重复、不符合机器学习标准、输血非主要结局以及全文不可用[2]。这些排除决策多数需要全文本信息才能做出准确判断。

## 3. 证据支持的研究方向

**3.1 人机协作的筛选模式**

现有证据支持采用人机协作而非完全自动化的筛选模式。cGPT作为“第二评审者助手”的可靠性表现表明，自动化工具可以在人类监督下发挥辅助作用[3]。这一发现与“检索-摘要-验证”范式相呼应，该范式主张利用大语言模型的摘要能力，同时保留人类对准确性和可靠性的验证责任[5]。

**3.2 针对摘要级信息的筛选策略优化**

鉴于多数语料仅有摘要可用，综述团队需要开发针对摘要信息的筛选策略。证据显示，范围综述的迭代性质允许“在筛选摘要和全文论文的过程中细化纳入标准”[1]。这意味着可以设计两阶段筛选流程：第一阶段基于摘要进行初步筛选，第二阶段对通过初步筛选的论文进行全文审查。

**3.3 自动化工具的持续验证与标准化**

现有研究强调需要“建立标准化的实际使用阈值”[3]，并呼吁“对ChatGPT模型在全文筛选中的应用进行更多研究”[3]。同时，证据表明需要“持续验证更先进的模型，以确定哪种角色最适合自定义GPT的能力”[3]。

## 4. 摘要级证据的局限

本合成面临的核心局限在于，所提供的证据集本身主要基于摘要级信息。具体而言：

- 纳入的8篇文献中，部分研究（如[3]）虽然评估了全文筛选的自动化方法，但其自身在本文中仅以摘要形式呈现，无法获取其完整的方法学细节和结果数据。
- 关于全文本阅读必要性的方法论讨论[1]虽然提供了理论框架，但缺乏对摘要与全文之间信息差距的量化分析。
- 机器学习在输血医学综述[2]中报告的全文排除原因（如“全文不可用”）提示，当仅有摘要可用时，某些资格标准（如机器学习方法的具体实现细节）可能无法得到充分评估。
- 证据合成术语分类的范围综述[8]识别了1010个独特术语来描述证据合成类型，但未提供这些术语在摘要与全文之间的一致性分析。

## 5. 谨慎结论

基于现有摘要级证据，自动化综述管线在处理需要全文本阅读的资格筛选标准时，应采取以下策略：

第一，采用两阶段筛选流程，第一阶段基于摘要进行初步资格判断，第二阶段对通过初步筛选的论文进行全文审查。这一策略与范围综述的迭代方法论一致[1]。

第二，在全文筛选阶段引入人机协作模式，将自动化工具（如定制GPT）作为第二评审者的辅助工具，而非完全替代人类评审者。现有证据表明，cGPT作为“第二评审者助手”角色时达到了可接受的可靠性水平[3]。

第三，建立明确的自动化工具使用边界，认识到当前大语言模型在事实准确性方面的局限性[5][6]，确保人类评审者对最终筛选决策保留控制权。

第四，对仅有摘要可用的文献，应在综述报告中明确标注其资格判断的不确定性，并在可能的情况下尝试获取全文或联系作者。

第五，持续关注自动化工具在全文筛选中的验证研究，特别是针对不同学科领域和资格标准类型的适用性评估[3][8]。

需要强调的是，本合成基于摘要级证据，其结论的稳健性受到原始文献信息完整性的限制。未来研究应直接比较基于摘要与基于全文的资格筛选决策的一致性，并开发针对摘要级信息优化的自动化筛选算法。
