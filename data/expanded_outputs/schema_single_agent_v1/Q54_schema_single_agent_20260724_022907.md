## 1. 检索与筛选概览

本合成基于提供的限定证据集E_q，共包含8条摘要级记录。这些记录涵盖多智能体对抗系统在系统综述中的应用[1]、自动化系统综述工具评估方案[2]，以及多篇来自eLife期刊的公开评审意见[3][4][5][6][7][8]。其中，直接涉及“多轮审稿循环”中“审稿人-修改者”互动机制的核心文献为[1]，该文献提出了一个具有可验证证据和批评循环的作者-审稿人工作流框架。其余记录[2]-[8]虽涉及审稿过程或自动化评估，但均未直接讨论审稿循环中的重复劳动与博弈问题。

## 2. 核心主题与证据

证据集内直接回应研究查询的核心文献仅有[1]。该文献描述了一种“对抗性多智能体系统”，其核心设计是通过“可验证证据”和“批评循环”来构建作者与审稿人之间的工作流[1]。这一框架的隐含逻辑在于：通过结构化的证据验证和批评反馈机制，迫使审稿人与修改者围绕具体证据展开实质性互动，而非进行形式化的重复劳动。然而，该文献仅提供摘要级证据，未详细说明如何具体避免重复劳动、如何界定“真正博弈”的操作性定义，也未提供实证数据证明其有效性。

其余文献[2]-[8]均未直接涉及多轮审稿循环中的重复劳动问题。[2]关注的是自动化工具（如EPPI-Reviewer和Copilot 365）在系统综述筛选、数据提取等环节的准确性和效率，其研究设计涉及两名独立审稿人解决冲突，但未讨论审稿循环中的博弈机制。[3][4][5][6][7][8]均为eLife期刊的公开评审意见，其内容分别涉及蝙蝠群体涌现建模、线虫成像系统、TRPM亚家族结合口袋等具体科学问题，与审稿流程设计无直接关联。

## 3. 证据支持的研究方向

基于现有证据，可识别以下研究方向：

第一，对抗性多智能体系统的实证评估。文献[1]提出了一个理论框架，但缺乏实证检验。未来研究可设计对照实验，比较采用该框架与常规审稿流程在减少重复劳动、提升博弈质量方面的效果。

第二，自动化工具在审稿循环中的角色定位。文献[2]评估了AI工具在系统综述流程中的表现，但未涉及多轮审稿循环。可探索如何将AI工具（如Copilot 365）整合到审稿-修改循环中，作为辅助证据验证或冲突解决的中介，而非替代人类博弈。

第三，审稿循环中“重复劳动”的量化指标。当前证据集未提供任何关于重复劳动的操作化定义或测量方法。需开发可量化的指标（如修改轮次中重复提出的相同意见比例、修改版本中未响应意见的比例等），以便系统评估不同审稿流程的效率。

## 4. 摘要级证据的局限

本合成面临显著的证据局限性。首先，核心文献[1]仅提供摘要级描述，缺乏方法细节、实证数据和结果分析，无法判断其提出的“对抗性多智能体系统”是否真正解决了重复劳动问题。其次，证据集中多数记录[3][4][5][6][7][8]与查询主题无关，它们作为公开评审意见存在，但内容聚焦于具体科学发现而非审稿流程设计。再次，文献[2]虽涉及自动化审稿工具，但其研究方案聚焦于单轮筛选和提取，未涉及多轮循环中的博弈动态。最后，所有证据均为摘要级，无法获取全文信息以验证其方法学质量和结论可靠性。

## 5. 谨慎结论

基于当前有限的摘要级证据，可得出以下谨慎结论：

第一，文献[1]提出的对抗性多智能体系统为减少审稿循环中的重复劳动提供了理论可能性，其核心在于通过可验证证据和批评循环构建结构化博弈机制。然而，该框架的有效性尚未得到实证检验。

第二，现有证据不足以支持任何关于如何避免重复劳动的具体操作建议。文献[2]提示自动化工具可辅助审稿流程，但其设计未针对多轮循环中的博弈问题。

第三，证据集中多数记录与查询主题无关，表明当前学术文献中关于“审稿循环中重复劳动与博弈”的系统性研究尚属空白。

综上，本合成无法就如何避免多轮审稿循环中的重复劳动给出确定性结论。未来研究需在对抗性多智能体系统框架下开展实证研究，并开发量化指标以区分重复劳动与真正博弈。
