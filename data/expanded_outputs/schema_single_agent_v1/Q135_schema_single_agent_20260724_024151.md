# 面向数字人文学科实体抽取规模化评估的精度与召回率代理指标：一项学术综合报告

## 1. 检索与筛选概览

本报告基于提供的八篇文献证据集（E_q），聚焦于一个核心研究问题：在数字人文学科（DH）实体抽取任务中，当需要大规模自动化评估而无法依赖人类专家时，哪些精度（Precision）与召回率（Recall）代理指标可以替代人工评估。所检索的文献涵盖2023年至2026年间的跨学科研究，包括预印本、期刊论文及会议论文，涉及人工智能辅助证据提取、文献筛选自动化、大型语言模型（LLM）基准测试以及技术批判等多个领域。经过筛选，其中六篇文献直接提供了与评估代理指标相关的实证证据或方法论框架，两篇文献（[2]和[4]）虽未直接涉及精度/召回率指标，但提供了重要的背景性批判视角。

## 2. 核心主题与证据

### 2.1 基于LLM的自动化筛选与抽取中的精度与召回率表现

多项研究直接报告了LLM在自动化文献筛选和证据抽取任务中的精度与召回率指标，这些指标可作为人类专家评估的代理。在环境系统综述领域，[7]的研究显示，GPT-4在标题与摘要筛选任务中，当概率阈值为0.5时实现了100%的召回率，意味着没有遗漏相关论文，同时可节省50%的人工筛选时间；当阈值调整至召回率仍高于95%时，可节省75%的人工时间。这一发现表明，召回率可以作为衡量自动化系统是否“不遗漏关键信息”的核心代理指标。

在生物医学文献筛选领域，[6]验证了一个完全本地化、开放权重的模式约束型LLM流水线，在三个系统综述基准测试中取得了差异化的表现：氯胺酮/神经影像学任务实现100%召回率（41/41）和89.1%精度（41/46），审计调整后的F1达97.8%；氯氮平/自杀倾向任务召回率为64.7%（33/51），审计调整后F1为72.0%；氯氮平/患者视角任务召回率为74.1%（20/27），审计调整后F1为83.7%。该研究明确指出，摘要级提取能够恢复硬元数据而不产生损坏，并生成与参考综述内容主题一致的证据图谱，但随机人工审计仍属必要。

### 2.2 多维度评估框架中的代理指标

[3]提出的BELO基准测试框架展示了如何将精度、宏观F1分数与多种文本生成指标（如ROUGE、BERTScore、BARTScore、METEOR、AlignScore）结合使用，作为人类专家评估的代理。在该框架中，GPT-5在眼科知识问答中达到最高精度0.90和宏观F1 0.91，但文本生成指标得分普遍较低（20.4-72.0分，满分100），表明临床推理能力仍有提升空间。这一对比揭示了单一精度指标不足以全面评估系统性能，需要多维度代理指标的组合。

### 2.3 自动化证据提取中的精度与召回率权衡

[1]在气候政策参与证据提取研究中指出，结合布局感知解析、Nomic嵌入模型和少样本提示策略的RAG系统在提取和分类多语言企业文档证据方面表现最佳，但研究同时强调，自动化系统应增强而非取代专家判断，以确保准确性。这暗示了在精度与召回率之间需要根据任务风险进行权衡。

### 2.4 评估框架中的局限性分类

[5]提出的LLM可行性框架将应用分为三类，并指出不同类别面临不同的根本性局限：缺乏理解、缺乏可预测性（幻觉风险）和缺乏共情。该框架可用于识别哪些应用场景下精度与召回率代理指标可能失效，特别是当输出需要临床监督（类别2）时，缺乏可预测性会直接影响召回率的可靠性。

## 3. 证据支持的研究方向

基于上述证据，以下研究方向得到支持：

**方向一：召回率优先的代理评估策略。** 在需要确保不遗漏关键实体或文献的场景中，召回率可作为首要代理指标。[7]和[6]的证据表明，通过调整概率阈值，可以在保持高召回率的同时大幅节省人工成本。对于数字人文学科的大规模实体抽取，可采用类似策略，优先确保高召回率，再通过抽样审计控制精度。

**方向二：多指标融合的评估框架。** [3]和[5]的研究表明，单一精度或召回率指标不足以全面评估系统性能。建议构建包含精度、召回率、F1分数以及文本生成质量指标（如ROUGE、BERTScore）的多维评估框架，以捕捉不同维度的系统表现。

**方向三：审计调整后的代理指标。** [6]提出的“审计调整后F1”概念值得借鉴，即对流水线检索到的但不在参考集中的记录进行人工裁决，从而获得更准确的性能估计。这种方法可在缺乏完整人工标注的情况下提供更可靠的代理评估。

**方向四：任务特定阈值优化。** [7]展示了如何通过调整概率阈值在召回率与效率之间取得平衡。数字人文学科实体抽取任务应根据领域特点和错误成本，确定最优的精度-召回率权衡点。

## 4. 摘要级证据的局限

本报告所依赖的摘要级证据存在若干固有局限：

**第一，上下文缺失与细节模糊。** 摘要通常无法提供完整的实验设置、数据集特征和统计显著性信息。例如，[7]明确承认其评估仅基于一项系统综述和一个提示词，结论的泛化性有限。[6]也指出，当摘要信息不足或缺乏信息性时，召回率会显著下降（如氯氮平/自杀倾向任务召回率仅64.7%）。

**第二，时效性与技术迭代风险。** 所引用文献中LLM版本（如GPT-4、GPT-5）和评估基准（如BELO）可能已被更新版本超越。特别是[5]提出的框架虽然指出了根本性局限，但也承认这些局限可能随技术发展而变化。

**第三，领域特异性限制。** 多数证据来自生物医学和环境科学领域，直接应用于数字人文学科实体抽取时需谨慎。数字人文学科特有的实体类型（如历史人物、地名、事件）和文本特征（如多语言、古文献）可能对代理指标的有效性产生不同影响。

**第四，缺乏直接对比研究。** 现有文献中缺乏将不同代理指标（如精度、召回率、F1、ROUGE、BERTScore）在相同数字人文学科任务上进行系统对比的研究，因此难以确定最优指标组合。

## 5. 谨慎结论

基于现有摘要级证据，可以得出以下谨慎结论：

**第一，召回率可作为数字人文学科实体抽取规模化评估的核心代理指标。** [7]和[6]的证据一致表明，通过适当阈值调整，LLM可以在保持高召回率的同时显著降低人工成本。对于数字人文学科中需要确保不遗漏关键实体的任务（如历史文献实体索引），召回率优先策略具有可行性。

**第二，精度与召回率需结合使用，并辅以审计调整。** [6]的审计调整后F1指标提供了一种在缺乏完整人工标注时获得更可靠评估的方法。建议在数字人文学科实践中采用“高召回率自动化筛选 + 随机人工审计”的混合策略。

**第三，多维度评估框架优于单一指标。** [3]和[5]的研究表明，结合精度、召回率、F1分数及文本生成质量指标的多维框架能更全面地反映系统性能。数字人文学科应根据具体任务需求（如实体类型、文本复杂度、错误容忍度）选择适当的指标组合。

**第四，当前证据的领域特异性要求进一步验证。** 现有研究主要集中于生物医学和环境科学，数字人文学科特有的评估需求（如对历史语境的理解、多语言处理、古文献识别）可能对代理指标的有效性产生显著影响。建议在数字人文学科具体任务上进行基准测试，以验证上述代理指标的适用性。

**第五，人类专家评估仍不可完全替代。** [1]明确强调自动化系统应增强而非取代专家判断，[6]也指出当摘要信息不足时仍需全文专家综合。因此，代理指标应被视为降低人工成本的工具，而非完全替代人类评估的手段。
