# 面向多智能协同情报服务的查询设计：单智能体与多智能体能力差异的区分

## 1. 检索与筛选概览

本合成基于提供的8篇文献证据，聚焦于“面向多智能协同情报服务，什么样的query最能区分单智能体与多智能体能力差异”这一研究问题。证据集涵盖多智能体信息检索系统[1]、大语言模型驱动的自然语言转查询语言[2]、医疗领域多智能体问答框架[3]、生物医学证据提取[4]、系统综述布尔查询生成[5]、MeSH术语自动建议[6]、生成式AI驱动的智慧图书馆信息搜索[7]以及多智能体通信拓扑自动设计[8]等主题。这些文献从不同角度揭示了单智能体与多智能体在查询处理能力上的关键差异点。

## 2. 核心主题与证据

### 2.1 查询复杂度与多智能体优势的关联

证据表明，多智能体系统在处理复杂查询时展现出显著优势。在医疗领域，多智能体框架通过分工协作——临床推理智能体生成结构化解释、证据检索智能体查询PubMed、精炼智能体提升清晰度和事实一致性——实现了87%的准确率和约0.80的相关性，而单智能体模型在零样本评估中表现较弱[3]。类似地，多智能体信息检索系统通过信息 scent 建模和查询日志挖掘，能够有效处理小规模搜索查询难以推断用户信息需求的问题[1]。

### 2.2 需要多步推理与证据整合的查询

最能区分单智能体与多智能体能力的查询类型是那些需要多步推理和跨源证据整合的复杂查询。例如，临床研究问题“干细胞移植是否能改善克罗恩病患者的生活质量？”需要从多篇研究中提取并综合冲突性证据[4]。多智能体系统通过URCA框架（统一检索聚类增强）在证据提取任务上比现有最佳方法F1分数提升高达10.3%[4]，而单智能体模型难以处理这种需要多源证据对比和综合的查询。

### 2.3 需要动态角色分配与拓扑设计的查询

多智能体系统的核心优势在于其协作拓扑的灵活性。ARG-Designer框架能够根据自然语言任务查询，动态确定所需智能体数量、选择适当角色并建立最优通信链路[8]。这种能力使得多智能体系统能够适应任务特定的需求，而单智能体系统受限于固定的交互结构。因此，那些需要动态调整处理策略、涉及多领域知识交叉的查询（如跨学科系统综述查询）最能凸显多智能体的优势。

### 2.4 需要验证与纠错的查询

单智能体模型在生成查询时存在可靠性问题。ChatGPT虽然能生成高精度的布尔查询，但以牺牲召回率为代价[5]；而多智能体框架通过引入验证层（如蒙特卡洛dropout和困惑度不确定性评分）和偏差检测机制，能够有效缓解单模型限制[3]。因此，那些对结果可靠性要求极高、需要内置验证机制的查询（如临床决策支持查询）最能区分两类系统的能力差异。

## 3. 证据支持的研究方向

基于现有证据，以下研究方向值得深入探索：

**方向一：多步推理型查询的标准化评估**。需要构建专门评估多智能体系统在复杂推理任务中优势的基准测试集，类似CochraneForest[4]但扩展至更多领域。

**方向二：动态拓扑适应型查询的设计**。借鉴ARG-Designer[8]的思路，研究如何设计查询使其能够自动触发多智能体系统的角色分配和通信拓扑优化。

**方向三：验证密集型查询的对比研究**。系统比较单智能体与多智能体在需要内置验证和纠错的查询（如医疗证据合成[3]）上的表现差异。

**方向四：人智协同查询的认知增益评估**。基于智慧图书馆的“意图感知+认知建构+内容生成”服务模式[7]，研究多智能体系统如何通过协同认知提升查询结果的质量。

## 4. 摘要级证据的局限

本合成基于摘要级证据，存在以下局限：首先，多数文献[3][4][5][6][8]为预印本，未经同行评审，其结论的可靠性有待验证。其次，摘要信息有限，无法获取详细的实验设计、数据集构成和统计显著性检验结果。例如，多智能体框架在医疗问答中87%的准确率[3]缺乏置信区间和基线对比的完整信息。第三，部分文献[1][7]的发表年份较早或来自非顶级会议，其技术方案可能已被后续研究超越。第四，证据集缺乏直接比较单智能体与多智能体在相同查询集上表现的对照实验，限制了直接推断能力差异的可靠性。

## 5. 谨慎结论

综合现有证据，最能区分单智能体与多智能体能力差异的查询具有以下特征：**需要多步推理与跨源证据整合**（如临床研究问题[4]）、**需要动态角色分配与协作拓扑设计**（如复杂任务查询[8]）、**需要内置验证与纠错机制**（如高可靠性要求的医疗查询[3]）以及**需要多领域知识交叉**（如跨学科系统综述查询[5][6]）。这些查询类型能够充分暴露单智能体在推理深度、证据综合、错误检测和任务适应性方面的局限，同时凸显多智能体系统通过分工协作、动态配置和验证层带来的性能提升。然而，现有证据主要来自特定领域（医疗、信息检索）的案例研究，缺乏跨领域的系统性对比实验。未来研究应构建标准化的多维度查询评估框架，在控制条件下直接比较两类系统在不同查询类型上的表现差异，以建立更可靠的区分标准。
