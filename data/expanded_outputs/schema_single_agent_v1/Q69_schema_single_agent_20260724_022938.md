# 冻结语料库设置下，检索策略的选择如何影响证据覆盖率和引用孤儿率？

## 1. 检索与筛选概览

本合成基于一个由8篇文献构成的冻结语料库（E_q），涵盖2016至2023年间发表的学术成果。这些文献涉及人工智能（AI）与聊天机器人[2][5][6][7]、多智能体系统[3]、6G网络[1]、能源市场[4]以及信息系统使用理论[8]等多元主题。语料库中文献的摘要级证据均来自不同学科领域，缺乏统一的检索策略设计说明，因此无法直接评估检索策略对证据覆盖率和引用孤儿率的影响。然而，通过分析这些文献的摘要内容，可以间接推断检索策略的选择如何塑造了当前证据集合的构成及其潜在缺陷。

## 2. 核心主题与证据

本语料库的核心主题集中在AI技术接受与聊天机器人应用领域。具体而言：

- **AI接受因素**：多项研究探讨了用户对AI技术的接受度。一项系统综述指出，感知有用性、绩效期望、态度、信任和努力期望是预测行为意图的关键因素，但文化情境下人类接触需求可能无法被AI替代[7]。另一项研究在旅游情境下扩展了技术接受模型（TAM），发现感知易用性、感知有用性、感知信任、感知智能和拟人化显著影响聊天机器人采用意图[6]。

- **聊天机器人设计与效果**：实验研究表明，拟人化设计线索和“登门槛”技术能显著提高用户对聊天机器人请求的遵从度，且社会临场感中介了拟人化设计对用户遵从的影响[5]。

- **多智能体与代理系统**：多智能体学习系统面临复杂性挑战[3]，而能源领域中的“产消者”被描述为既消费又生产能源的代理，其市场整合涉及点对点模型和社区群体模式[4]。信息系统使用研究则关注向代理性信息系统委托权利与责任的理论框架[8]。

- **其他技术领域**：6G网络愿景涉及太赫兹通信、超大规模天线阵列、量子通信等前沿技术[1]；ChatGPT的综述则强调了其伦理挑战、数据偏见和安全问题[2]。

## 3. 证据支持的研究方向

基于现有摘要级证据，可识别以下研究方向：

- **AI接受与拟人化设计**：拟人化设计对用户遵从的促进作用[5]以及感知智能、拟人化对采用意图的影响[6]表明，人机交互中的社会线索是重要研究方向。

- **文化情境与人类接触需求**：系统综述指出，在某些文化情境下，人类接触需求可能无法被AI替代[7]，这提示需要跨文化比较研究。

- **代理性系统的委托机制**：向信息系统委托权利与责任的理论框架[8]与多智能体系统[3]及产消者市场模型[4]存在概念关联，可探索代理性系统在不同领域的委托机制。

- **技术伦理与偏见**：ChatGPT的伦理挑战和偏见问题[2]与AI接受研究中的信任因素[7]形成交叉，需进一步研究伦理设计对用户接受的影响。

## 4. 摘要级证据的局限

本合成所依赖的摘要级证据存在显著局限：

- **检索策略不可知**：语料库未提供任何文献的检索策略描述，无法判断检索词、数据库选择、筛选标准等如何影响证据覆盖率。例如，若检索策略偏向“AI接受”关键词，则可能遗漏未使用该术语的相关研究，导致引用孤儿率升高。

- **领域碎片化**：语料库包含6G网络[1]、能源市场[4]等与核心主题关联较弱的文献，这可能源于宽泛的检索策略（如“智能系统”或“代理”），导致证据覆盖分散，部分文献成为孤立引用。

- **摘要信息有限**：摘要仅提供研究背景和主要发现，缺乏方法细节、样本特征、效应量等关键信息。例如，关于拟人化设计对用户遵从的影响[5]，摘要未报告实验的具体设计、样本量或统计显著性水平。

- **时间与地域偏差**：文献发表时间跨度大（2016-2023），且部分研究聚焦印度[6]等特定地区，可能引入时间滞后和地域偏差，影响证据的时效性和普适性。

## 5. 谨慎结论

在冻结语料库设置下，检索策略的选择对证据覆盖率和引用孤儿率具有决定性影响，但本语料库的构成无法直接追溯其检索策略。基于现有摘要级证据，可以谨慎推断：

1. **宽泛检索策略**可能导致证据覆盖分散，引入与核心主题关联度低的文献（如6G网络[1]），增加引用孤儿率，因为这些文献在后续分析中可能缺乏与其他证据的关联。

2. **聚焦检索策略**（如限定“AI接受”或“聊天机器人”）可能提高核心主题的证据密度，但会遗漏跨领域关联（如多智能体系统[3]与代理性委托理论[8]的潜在联系），降低证据覆盖率。

3. **摘要级证据的固有局限**（信息不完整、方法细节缺失）进一步放大了检索策略选择的影响，因为研究者无法通过摘要判断文献的方法学质量或具体情境适用性。

因此，在冻结语料库研究中，检索策略需在覆盖广度与主题聚焦之间谨慎权衡，并应明确报告检索参数以增强可复现性。未来研究应结合全文分析，以更准确地评估检索策略对证据合成质量的影响。
