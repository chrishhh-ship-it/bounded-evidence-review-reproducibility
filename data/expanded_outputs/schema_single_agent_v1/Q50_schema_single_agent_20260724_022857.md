## 学术情报综合

### 1. 检索与筛选概览
本综合基于提供的8篇文献证据，围绕“结果与讨论章节应如何分离，以避免系统把结构性指标夸大为理论贡献”这一研究问题展开。所涉文献涵盖6G网络愿景[1]、ChatGPT综述[2]、多智能体系统[3]、电力市场设计[4]、AI聊天机器人用户依从性[5]与采纳[6]、AI接受度系统综述[7]以及信息系统使用中的委托理论框架[8]。这些文献均来自2016至2023年间的高质量期刊或会议，但未直接涉及学术写作中“结果与讨论”章节分离的方法论问题。因此，本综合将基于摘要级证据，从间接相关的理论视角和实证发现中提取可迁移的见解。

### 2. 核心主题与证据
现有证据表明，在AI和信息系统领域，研究者常将结构性指标（如系统性能、用户采纳率、技术特征）直接等同于理论贡献，而忽视了理论机制的解释。例如，在6G网络研究中，作者列举了太赫兹通信、超大规模天线阵列等技术指标，但未深入讨论这些指标如何改变网络架构的理论基础[1]。类似地，ChatGPT综述虽提及伦理挑战和偏见，但主要聚焦于应用场景描述，而非理论性反思[2]。在AI聊天机器人研究中，用户依从性被归因于拟人化设计线索和一致性需求，但作者未区分这些结构性特征（如界面设计）与理论机制（如社会响应理论）的贡献层次[5]。此外，一项系统综述发现，多数AI接受度研究未明确定义AI，且依赖自我报告数据，这可能导致将感知有用性等结构性指标误判为理论贡献[7]。这些证据共同指向一个风险：当结果章节仅报告结构性指标（如性能数据、采纳率），而讨论章节未将这些指标置于理论框架中加以解释时，系统容易夸大其理论意义。

### 3. 证据支持的研究方向
基于上述证据，可识别出三个研究方向以改善结果与讨论的分离：
- **理论锚定方向**：在讨论章节中，应将结构性指标（如系统性能、用户行为数据）与特定理论（如委托理论[8]、技术接受模型[7]）明确关联，而非仅描述指标本身。例如，在AI聊天机器人研究中，拟人化设计对用户依从性的影响应被解释为“社会响应理论”的实证检验，而非单纯报告统计显著性[5]。
- **机制解释方向**：结果章节应聚焦于“是什么”（如用户采纳率），而讨论章节应聚焦于“为什么”（如信任、感知智能等中介机制）。现有研究常将中介变量（如信任）作为理论贡献，但未区分其作为结构性指标与理论机制的角色[6][7]。
- **局限性反思方向**：讨论章节应主动识别结构性指标的边界条件，例如，在电力市场设计中，作者虽提出三种市场模型，但强调“复杂性”和“未知风险”作为限制[4]。这种反思可防止将模型结构本身夸大为普适理论。

### 4. 摘要级证据的局限
本综合依赖的摘要级证据存在显著局限。首先，所有文献均未直接讨论“结果与讨论章节分离”的方法论问题，因此本综合的推断基于间接类比。其次，摘要信息可能省略了原文中关于理论贡献的详细讨论，例如，多智能体系统综述[3]和委托理论框架[8]的摘要未提供足够细节来评估其如何区分结构性指标与理论贡献。此外，部分文献（如6G网络[1]）属于技术展望类，其摘要天然偏向技术指标而非理论反思。这些局限意味着本综合的结论应被视为初步假设，而非确定性指南。

### 5. 谨慎结论
为避免系统将结构性指标夸大为理论贡献，结果与讨论章节应遵循以下分离原则：结果章节仅报告可观察的结构性指标（如性能数据、用户行为统计），而讨论章节必须将这些指标置于理论框架中，解释其机制、边界条件和理论意义。现有证据表明，在AI和信息系统研究中，常见错误包括将技术特征（如拟人化设计）直接视为理论贡献[5]，或未定义核心概念（如AI）[7]。建议研究者采用委托理论[8]或技术接受模型[7]等框架，在讨论中明确区分“结构性指标”与“理论机制”。然而，由于缺乏直接针对该问题的实证研究，上述结论需通过专门的方法论研究加以验证。
