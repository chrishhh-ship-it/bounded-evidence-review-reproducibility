# 合成智能体报告：合成智能体需从原始研究中保留哪些信息以支持下游GRADE间接性评估

## 1. 检索与筛选概览

本合成基于提供的8篇文献记录，涵盖农业推广服务[1]、转诊干预[2]、社区医疗服务体验[3]、综述方法论[4]、皮肤病临床指南[5]、自动化数据提取系统[6]、气候变化综合报告[7]以及公共交通信息可用性[8]等多元主题。这些文献均以摘要级证据形式呈现，未提供全文数据。根据GRADE间接性评估的要求，合成智能体需从原始研究中保留的关键信息包括：研究人群特征、干预措施细节、对照条件、结局指标以及研究情境（如地理、时间、医疗环境等），以便判断证据与目标问题的匹配程度。然而，当前证据集仅包含摘要级信息，缺乏详细的方法学描述和完整的PICO（人群、干预、对照、结局）要素，这限制了间接性评估的全面性。

## 2. 核心主题与证据

从提供的文献中，可识别出与间接性评估相关的若干核心主题：

**（1）研究情境与适用性**：多项研究强调情境因素对证据可转移性的影响。例如，农业推广服务研究聚焦于加纳东北部的小农户，其气候适应策略受当地土地权属安排和农民变革阻力等特定障碍影响[1]。转诊干预的系统综述指出，干预措施的成功“取决于具体临床情境”，且“没有一刀切的方法”[2]。这提示合成智能体必须保留研究的地理、文化和组织情境信息，以评估证据与目标情境的间接性。

**（2）干预复杂性与多组分特征**：转诊干预研究中，13项评估了多组分干预，而单独使用的转诊算法和员工教育在改善转诊率或适当性方面效果较差[2]。这表明合成智能体需详细记录干预的组分、实施方式和理论框架（如TiDiER框架[2]），因为干预的复杂性直接影响其在不同环境中的可转移性。

**（3）患者体验与结局测量**：多专业社区提供者（MCPs）的实证综合发现，患者层面的护理规划可改善患者体验，但证据支持强度因结局指标而异[3]。GRADE间接性评估要求明确结局指标的定义、测量工具和重要性排序（如患者代表对结局的评分[5]），合成智能体需保留这些信息以判断结局与目标问题的相关性。

**（4）证据质量与综述方法**：一篇方法论论文挑战了系统综述优于叙述性综述的“虚假层级”，指出系统综述可能因严格纳入标准而排除相关证据，导致知识景观偏斜[4]。这提示合成智能体在保留原始研究信息时，需同时记录综述方法本身（如是否使用GRADE、AMSTAR、MMAT等工具[3][5]），因为方法选择影响证据的可信度和间接性判断。

**（5）自动化提取的可靠性**：一项关于自动化系统提取诊断数据的基准研究强调，系统需在“正确性、弃权行为、可重复性和操作效率”方面接受评估[6]。这间接表明，当合成智能体依赖自动化工具提取原始研究信息时，需保留提取过程的可靠性指标，否则下游间接性评估可能基于错误或不完整的数据。

## 3. 证据支持的研究方向

基于上述证据，合成智能体在支持下游GRADE间接性评估时，应优先保留以下信息维度：

**（1）人群特征与纳入/排除标准**：包括年龄、性别、免疫状态（如器官移植受者[5]）、疾病风险分层（如低、高、极高风险皮肤鳞状细胞癌[5]）以及共病情况。例如，皮肤癌指南明确区分了低风险、高风险和极高风险患者的治疗建议[5]，若目标人群风险分层不同，则间接性显著。

**（2）干预与对照的详细描述**：包括干预组分（如多组分vs.单组分[2]）、实施者（如全科医生、专科护士[5]）、剂量（如随访频率：高风险患者每4个月一次，持续12个月[5]）以及对照条件（如观察、标准治疗[5]）。转诊干预研究指出，电子健康系统、转诊算法和协作工作是最常用的流程和系统变革[2]，这些细节对判断干预是否适用于其他环境至关重要。

**（3）结局指标及其重要性排序**：需保留结局的定义、测量时间点、测量工具以及患者或利益相关者对其重要性的评级（如GRADE方法中9分制评分[5]）。例如，皮肤癌指南中患者代表将“局部复发”评为关键结局[5]，若目标研究使用不同结局定义，则间接性增加。

**（4）研究设计与实施情境**：包括研究设计（如随机对照试验、真实主义综合[3]）、研究地点（如英国NHS[5]、加纳[1]）、时间范围（如2007-2020年[5]）以及实施障碍（如时间限制、后勤问题、患者/员工先入为主的观念[2]）。这些信息帮助评估证据与目标情境的匹配度。

**（5）方法学质量与偏倚风险**：需保留质量评估工具（如JBI工具[2]、MMAT[3]、GRADE[5]）及其结果，因为低质量证据可能增加间接性评估的不确定性。

## 4. 摘要级证据的局限

本合成面临的核心局限在于仅依赖摘要级证据，这严重限制了间接性评估的深度和准确性：

**（1）PICO要素不完整**：摘要通常仅提供研究目的和主要发现，缺乏详细的纳入/排除标准、干预实施细节、对照条件描述以及结局测量方法。例如，农业推广研究摘要未说明具体干预内容（如ICT培训的具体模块）[1]，转诊干预摘要未列出所有多组分干预的组成部分[2]。

**（2）情境信息缺失**：摘要无法提供研究实施的具体情境细节，如医疗系统结构（如初级与二级护理的转诊路径[2]）、文化背景（如农民对变革的抵抗[1]）或政策环境（如英国NHS资源分配[5]）。这些信息对判断间接性至关重要。

**（3）方法学细节不足**：摘要通常不报告质量评估结果、偏倚风险判断或敏感性分析。例如，皮肤癌指南摘要虽提及使用GRADE，但未提供具体证据质量评级（如“低质量”或“极低质量”）[5]。方法论论文指出，系统综述可能因严格纳入标准而排除相关证据[4]，但摘要无法反映这种排除对间接性的影响。

**（4）结局定义模糊**：摘要中的结局指标常以概括性术语呈现（如“患者体验改善”[3]），缺乏操作化定义（如使用何种量表、最小临床重要差异值）。这导致无法判断结局与目标问题的可比性。

**（5）自动化提取的误差风险**：若合成智能体依赖自动化系统提取摘要信息，需注意这些系统可能产生“幻觉”或错误提取[6]。本合成中未使用自动化工具，但若未来应用，需保留提取过程的可靠性数据。

## 5. 谨慎结论

基于提供的摘要级证据，合成智能体在支持下游GRADE间接性评估时，必须保留以下关键信息：研究人群的详细特征（包括风险分层和免疫状态）、干预的多组分描述及实施情境、结局指标的定义与重要性排序、研究设计类型及方法学质量评估结果。然而，当前证据集仅包含摘要级信息，严重缺乏PICO要素、情境细节和方法学透明度，这使得全面的间接性评估难以实现。建议在未来的合成实践中，优先获取全文数据或至少包含详细方法学附录的研究报告（如皮肤癌指南的在线支持信息[5]）。此外，合成智能体应记录自身使用的提取方法（如是否采用自动化系统[6]）及其可靠性，以确保下游评估的透明度。最终，任何基于摘要级证据的间接性判断都应被视为初步且需谨慎解读，因为正如方法论论文所警示的，综述方法的选择本身可能引入偏倚[4]，而间接性评估的准确性最终取决于原始信息的完整性和可及性。
