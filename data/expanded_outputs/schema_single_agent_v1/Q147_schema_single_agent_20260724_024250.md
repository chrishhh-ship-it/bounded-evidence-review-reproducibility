# 数字人文语料库排除标准文档化：覆盖度与建构性权衡的评估基础

## 1. 检索与筛选概览

本合成基于所提供的八篇摘要级证据文献，涵盖系统综述方法论、数字人文理论、以及信息检索与验证技术等交叉领域。证据来源包括：医学教育领域的范围综述方法论讨论[1]、数字人文认知理论[2]、系统综述与叙事综述的层级争议[3]、具体领域范围综述案例[4][5]、大型语言模型在文献检索中的应用与局限[6]、以及系统综述操作指南[7][8]。这些文献共同构成了探讨数字人文（DH）语料库排除标准文档化问题的跨学科证据基础。

## 2. 核心主题与证据

### 2.1 排除标准文档化的认识论基础

范围综述的方法论强调，研究者需要基于可辩护的论证做出决策，并需在整个研究过程中进行反思性实践（reflexivity），质疑自身决策及其形成过程[1]。这一认识论立场与数字人文学科中关于工具与认知扩展的讨论相呼应：数字人文主要构建外部技术工具，而传统人文学科发展概念工具（包括理论），两者各有优势与局限，应寻求未来协同[2]。因此，DH语料库的排除标准文档化不仅是技术性记录，更是一种认识论承诺——研究者需明确其选择背后的理论立场与判断依据。

### 2.2 排除标准与“覆盖度-建构性”权衡

系统综述方法论强调使用严格的纳入与排除标准，通过详尽的检索策略将初始可能数以千计的潜在研究缩减至少数符合标准的文献[7]。然而，有学者指出，这种“高拒绝-纳入比”的方法可能过度强调技术性综合而忽视批判性反思，导致知识景观的显著偏斜[3]。叙事综述则通过专家判断和目的性选择来确保证据与关键政策问题的相关性，但面临“ cherry-picking ”的批评[3]。

在DH语料库构建中，这一权衡尤为关键：过于宽泛的纳入标准可能降低语料库的分析深度和理论建构能力；过于严格的排除标准则可能遗漏重要文化现象。范围综述的迭代特性允许在筛选过程中细化纳入标准[1]，这为DH语料库的动态调整提供了方法论参考。

### 2.3 文档化实践的具体要求

现有证据表明，有效的排除标准文档化应包含以下要素：
- **明确的决策记录**：使用工具（如Rayyan）跟踪纳入/排除决策，并记录清晰、简洁的决策理由[1]。
- **多层级透明度**：系统综述要求预先制定详细方案，包含严格的纳入和排除标准[7]；叙事综述则要求作者真实呈现支撑证据及其如何被用于形成结论[3]。
- **语境化信息**：干预研究综述建议提供关于干预设置、实施、目标群体、活动和材料的详细信息[4]，这一原则可迁移至语料库文档化——需记录语料来源、时间范围、语言、格式等语境参数。

### 2.4 技术工具与验证挑战

大型语言模型（如ChatGPT）在文献检索和摘要生成中展现出潜力，但其“幻觉”问题——生成看似可信但实际虚构的回应——构成了严重风险[6]。检索增强型LLM虽能减少直接使用虚假信息的风险，但会降低用户对来源的控制，导致结果可能与用户的最佳信息标准不一致[6]。这对DH语料库文档化的启示是：任何自动化工具辅助的排除决策都需经过人工验证，且文档化过程应保留人工判断的痕迹。

## 3. 证据支持的研究方向

基于现有证据，未来DH语料库排除标准文档化研究可朝以下方向发展：

**方向一：建立混合方法论框架**。借鉴系统综述的透明性要求与叙事综述的诠释性深度[3]，开发适用于DH语料库的文档化模板，既记录技术性排除决策（如语言、时间范围），也记录理论性排除理由（如研究范式、方法论取向）。

**方向二：开发反思性文档化工具**。借鉴范围综述中反思性实践的要求[1]，设计能够记录研究者决策过程、理论立场和认识论假设的文档化工具，使未来研究者能够评估排除标准背后的建构性考量。

**方向三：探索覆盖度评估的量化指标**。参考系统综述中“高拒绝-纳入比”的概念[3]，开发衡量DH语料库覆盖度与建构性之间关系的量化指标，如“排除理由多样性指数”或“理论立场透明度评分”。

**方向四：整合人机协作验证机制**。鉴于LLM在文献处理中的局限[6]，研究如何将人工判断与自动化工具结合，在保证效率的同时维持对排除决策的批判性审查。

## 4. 摘要级证据的局限

本合成基于摘要级证据，存在以下固有局限：

首先，摘要可能无法充分呈现原始研究的完整方法论细节。例如，关于范围综述迭代特性的讨论[1]在全文层面可能包含更具体的操作指南，而摘要仅提供概括性描述。

其次，证据来源主要来自医学和健康科学领域（[1][3][4][5][6][7][8]），其方法论框架虽具有参考价值，但直接迁移至数字人文学科需谨慎。数字人文的语料库构建涉及独特的文化分析问题（如文本表征、历史语境、多模态数据），这些在医学综述方法论中可能未被充分涵盖。

第三，部分文献发表于2017-2018年[3][7]，其关于系统综述与叙事综述的讨论可能未反映最新方法论发展。特别是关于LLM的讨论[6]发表于2023年，技术迭代迅速，其结论可能已部分过时。

最后，摘要级证据无法提供具体的案例分析和操作细节，限制了本合成对实践指导的深度。

## 5. 谨慎结论

DH语料库的排除标准文档化应超越简单的技术性记录，成为一种认识论实践。基于现有证据，可提出以下初步建议：

第一，文档化应同时包含“技术性排除理由”（如语言、时间范围、格式限制）和“建构性排除理由”（如理论立场、研究范式选择、对覆盖度-建构性权衡的考量）。

第二，借鉴范围综述的迭代方法论[1]，允许在语料库构建过程中根据初步发现调整排除标准，但需清晰记录每次调整的理由和影响。

第三，认识到“系统性”不等于“高质量”[3]，文档化的目标应是使未来研究者能够理解排除决策背后的判断逻辑，而非追求虚假的客观性。

第四，在利用自动化工具辅助排除决策时，需保持对“幻觉”风险[6]的警惕，确保关键决策保留人工验证痕迹。

最终，DH语料库排除标准的文档化应服务于一个核心目标：使未来研究者能够评估语料库的覆盖度与建构性之间的特定权衡，从而判断该语料库对其研究问题的适用性。这一目标与数字人文对工具与理论协同的追求[2]一脉相承。
