# 语料库构建决策对数字人文学科综合任务中下游引用基础失败预测强度的综合研究

## 1. 检索与筛选概览

本综合研究基于提供的八篇摘要级证据文献，涵盖2019年至2026年间发表的数字人文、证据综合方法、机器学习与人工智能应用等领域的相关研究。这些文献来自不同学术背景，包括数字人文[1]、证据综合方法学[2][5]、大型语言模型应用[3][8]、机器学习在医学中的应用[4]、以及特定领域的综合研究[6][7]。研究主题涉及语料库构建、证据综合自动化、模型评估与基准测试等多个维度，为分析语料库构建决策与下游引用基础失败之间的关系提供了多角度的证据基础。

## 2. 核心主题与证据

### 2.1 语料库构建决策的关键维度

从现有证据来看，语料库构建决策中几个关键维度可能影响下游引用基础的可靠性：

**数据质量与标准化问题**：证据表明，数据标准化程度不足会严重影响模型性能。在医药供应链管理中，不同系统使用不同的数据标准，导致“垃圾进垃圾出”现象，限制了大型语言模型从非结构化数据中提取有意义见解的能力[3]。同样，在输血医学的机器学习应用中，数据质量与报告标准的缺乏是主要挑战，多数研究为单中心研究且缺乏前瞻性验证[4]。

**语料库范围与代表性**：热浪定义研究表明，不同地区使用不同的定义标准，导致在应急管理、健康预警等方面产生广泛影响[6]。这种定义的不一致性反映了语料库构建中范围界定决策的重要性。

**训练数据的时效性与更新机制**：大型语言模型在医药供应链管理中的应用面临“保持模型更新困难”的挑战，因为训练需要大量计算资源和数据，而供应链管理是一个动态变化的领域，模型可能基于过时信息做出推荐[3]。

### 2.2 引用基础失败的表现形式

现有证据揭示了多种引用基础失败的表现：

**检索遗漏**：在证据综合中，生成式人工智能用于检索时遗漏了68%至96%的研究（中位数91%）[2]。这一高遗漏率直接反映了语料库构建决策对下游检索效果的影响。

**筛选与提取错误**：人工智能在筛选阶段做出错误纳入决策的比例为0%至29%（中位数10%），错误排除决策为1%至83%（中位数28%），错误数据提取为4%至31%（中位数14%）[2]。这些错误率表明，语料库构建的质量直接影响下游任务的准确性。

**基准测试的可靠性问题**：对前沿通用大型语言模型的审计发现，相当一部分表面错误实际上源于过时或模糊的基准标注，表明当前基准可能错误估计模型能力，从而误导部署决策[8]。

## 3. 证据支持的研究方向

### 3.1 语料库构建标准化与质量控制

证据强烈支持需要建立更严格的语料库构建标准和质量控制机制。在输血医学领域，研究指出需要“一致的报告和前瞻性验证”[4]。在气候变化证据综合中，强调需要“透明的方法学”和“正式的证据质量评估”[5]。这些发现表明，语料库构建决策的标准化可能是减少下游引用失败的关键路径。

### 3.2 混合架构与人机协作模式

多项证据支持采用混合架构和人机协作模式来缓解语料库构建决策带来的问题。在医药供应链管理中，建议“大型语言模型应被视为辅助工具而非人类替代品”[3]。在输血医学中，研究表明机器学习模型应“补充而非替代临床判断”[4]。前沿模型审计也指出，安全有效的临床应用需要“混合架构、外部基础事实和人在回路评估”[8]。

### 3.3 自动化辅助工具的开发与评估

BERT辅助文献筛选工作流的研究展示了自动化工具在提高筛选效率方面的潜力，该模型在相关研究分类中达到0.77的AUC值，并将筛选时间缩短至1142秒[7]。然而，该研究也指出纳入研究存在显著异质性（I²=86.85%），提示语料库构建决策对下游综合结果的影响。

### 3.4 证据综合方法学的跨领域整合

气候变化解决方案的证据综合呼吁整合“定量、定性和混合方法证据综合方法论”[5]，并强调需要发展“新颖的证据综合技术”来应对大规模文献的挑战。这种跨领域方法学整合可能有助于识别和缓解语料库构建决策带来的系统性偏差。

## 4. 摘要级证据的局限

本综合研究基于摘要级证据，存在以下固有局限：

**信息粒度不足**：摘要级证据无法提供语料库构建决策的具体参数、模型架构细节、或失败案例的完整描述。例如，关于“数据标准化”的讨论在摘要中仅以概括性表述出现[3]，无法深入分析具体哪些标准化决策最为关键。

**领域特异性限制**：现有证据主要来自医药、气候变化等特定领域，可能无法完全代表数字人文学科综合任务的特殊性。数字人文研究强调“短语学和风格”等文学特征[1]，这些特征在现有证据中缺乏直接对应。

**时间滞后性**：部分文献发表于2026年[7][8]，反映了最新技术发展，但语料库构建决策对下游影响的长期追踪研究仍然缺乏。

**因果推断困难**：现有证据多为相关性描述，难以建立语料库构建决策与下游引用失败之间的直接因果关系。例如，人工智能在证据综合中的高错误率[2]可能源于多种因素，而非单一的语料库构建决策。

## 5. 谨慎结论

基于现有摘要级证据，可以初步推断：语料库构建决策中数据标准化程度、范围界定清晰度、时效性维护机制、以及质量控制流程的完善程度，可能是预测下游引用基础失败的最强因素。证据表明，缺乏标准化[3]、不明确的定义范围[6]、过时的训练数据[3]、以及不充分的验证[4]都与下游任务性能下降相关。

然而，这些结论需要谨慎对待。现有证据主要来自医药和气候变化领域，数字人文学科综合任务可能面临独特的语料库构建挑战，如文学文本的多义性、历史语料的语境依赖性等。此外，摘要级证据无法提供足够的细节来量化不同决策维度的相对预测强度。

未来研究应致力于：(1) 在数字人文领域开展专门研究，系统评估语料库构建决策对下游引用基础的影响；(2) 建立标准化的语料库构建报告规范，提高研究的可重复性和可比性；(3) 发展混合人机协作框架，在利用自动化工具效率的同时保持人类监督[8]；(4) 探索跨领域方法学整合，借鉴医学和气候变化领域的证据综合经验[5]。
