# 中文智能综合报告

## 1. 检索与筛选概览

本综合报告基于提供的8篇摘要级证据文献，旨在探讨AI辅助系统评价中减少结果报告偏倚的协议预注册要求。检索范围涵盖2023年至2026年间发表的研究，包括系统评价方案、方法学论文和综述类文献。其中，[1]和[7]为具体的研究方案，分别关注ChatGPT在偏倚风险评估中的应用以及自动化系统评价流程的评估；[2]和[3]为系统评价类研究，总结了LLM在文献综述中的使用情况；[4]为方法学评论，探讨系统评价与叙述性评价的层级关系；[5]为系统评价的概述；[6]为系统评价方案；[8]则关注AI代理安全框架的治理缺口。这些文献共同构成了探讨AI辅助系统评价中协议预注册与偏倚控制问题的证据基础。

## 2. 核心主题与证据

现有证据表明，协议预注册在系统评价中具有重要地位，但针对AI辅助系统评价的具体预注册要求尚未形成统一标准。关键发现包括：

**（1）协议预注册的现有实践**：在传统系统评价中，协议预注册已被广泛采用。[3]的研究明确报告了PROSPERO注册号（CRD42023417336）和OSF DOI（10.17605/OSF.IO/87U6Q），表明预注册已成为系统评价的标准实践。[6]同样报告了国际前瞻性系统评价注册库的注册号（CRD42023474219），并声明遵循PRISMA指南。[7]也在开放科学框架（OSF）进行了注册（https://doi.org/10.17605/OSF.IO/49BX8）。这些案例表明，协议预注册是减少报告偏倚的重要机制。

**（2）AI辅助系统评价中的偏倚风险**：[1]的研究方案明确指出，偏倚风险评估是系统评价的核心环节，而ChatGPT等LLM可能支持这一任务，但需要评估其与人类评审者的一致性。该研究采用Cohen's κ作为一致性评估指标，并计划报告观察一致性、预期一致性和p值。[2]的LLM辅助系统评价发现，GPT模型在数据提取中的平均精确度为83.0%，召回率为86.0%，但数值数据提取的准确性较低。这些发现提示，AI工具在减少偏倚方面既有潜力也存在局限。

**（3）协议预注册对减少偏倚的作用**：[4]的方法学评论指出，系统评价的“系统性”特征包括预先确定的结构化方法，但同时也批评了将“系统性”简单等同于高质量的做法。该文强调，真正的偏倚控制需要透明和适当的方法，而不仅仅是机械地遵循预定义工具或检查表。这一观点对AI辅助系统评价尤为重要，因为AI工具的“黑箱”特性可能引入新的偏倚来源。

**（4）AI辅助系统评价的协议要求**：[7]的研究方案详细描述了自动化系统评价的评估方法，包括使用20%和40%的人工筛选阈值来评估优先筛选的准确性，以及使用Cohen's Kappa评估一致性。该方案明确注册了研究协议，体现了在AI辅助系统评价中保持方法学透明度的努力。

## 3. 证据支持的研究方向

基于现有证据，以下研究方向值得关注：

**（1）AI辅助系统评价的协议预注册标准**：需要制定专门针对AI辅助系统评价的协议预注册要求，包括明确AI工具的使用方式、评估指标（如Cohen's κ）、阈值设定（如[7]中使用的20%和40%筛选阈值）以及偏倚控制策略。[1]的研究方案为这一方向提供了初步框架。

**（2）AI工具在偏倚评估中的一致性验证**：[1]和[7]均强调评估AI与人类评审者之间一致性的重要性。未来研究应系统评估不同LLM（如GPT、BERT）在偏倚风险评估中的表现，并建立可接受的阈值标准。[2]的研究表明，GPT模型在数据提取中表现优于BERT模型，但这一发现需要进一步验证。

**（3）协议预注册对减少结果报告偏倚的效果评估**：需要比较有协议预注册和无协议预注册的AI辅助系统评价在结果报告偏倚方面的差异。[3]和[6]的注册实践可作为参考，但需要更多实证研究来量化预注册的实际效果。

**（4）AI辅助系统评价的方法学指南**：[4]的评论指出，系统评价与叙述性评价之间的界限模糊且存在争议。在AI辅助系统评价中，需要明确区分AI工具在哪些环节可以替代人类评审、哪些环节需要人类监督，以及如何确保方法学的透明性和可重复性。

## 4. 摘要级证据的局限

本综合报告基于摘要级证据，存在以下局限：

**（1）证据深度有限**：所有8篇文献均为摘要级信息，缺乏完整的全文数据。例如，[1]的研究方案仅描述了研究设计，尚未报告实际结果；[7]同样为方案阶段，未提供自动化系统评价的实际效果数据。这使得无法评估AI工具在减少结果报告偏倚方面的实际效果。

**（2）研究主题分散**：现有文献涵盖多个不同领域，包括医学干预的偏倚评估[1]、LLM辅助系统评价[2]、ChatGPT应用综述[3]、系统评价方法学[4]、血栓风险评估[5]、糖尿病虚拟咨询[6]、白内障证据缺口图更新[7]以及AI代理安全框架[8]。这些研究主题的异质性使得难以直接比较和综合关于协议预注册要求的具体证据。

**（3）缺乏直接证据**：目前没有文献直接探讨“协议预注册要求如何减少AI辅助系统评价中的结果报告偏倚”这一核心问题。[1]和[7]虽然涉及AI辅助系统评价，但主要关注AI与人类的一致性，而非预注册本身对偏倚的影响。[4]虽然讨论了系统评价的偏倚问题，但未涉及AI辅助场景。

**（4）时间跨度限制**：文献发表年份从2018年到2026年，其中[4]发表于2018年，其讨论的方法学问题可能未充分考虑AI技术的最新发展。而[8]发表于2026年，关注AI代理安全框架，与系统评价协议预注册的直接相关性较低。

## 5. 谨慎结论

基于现有摘要级证据，可以得出以下谨慎结论：

**（1）协议预注册是减少系统评价结果报告偏倚的重要机制**，这在传统系统评价中已得到广泛认可[3][6][7]。然而，针对AI辅助系统评价的专门预注册要求尚未建立，现有研究主要沿用传统系统评价的注册实践。

**（2）AI工具在系统评价中展现出减少偏倚的潜力**，特别是在数据提取和偏倚评估环节[1][2][7]。但AI工具的表现存在变异性，GPT模型在数据提取中的精确度为83.0%、召回率为86.0%[2]，而数值数据提取的准确性较低，提示AI辅助系统评价仍需人类监督。

**（3）协议预注册要求应涵盖AI工具使用的透明度**，包括明确说明AI工具的类型、版本、提示工程方法、评估指标（如Cohen's κ）以及人类监督的程度[1][7]。这有助于确保AI辅助系统评价的可重复性和可审计性。

**（4）现有证据不足以确定具体的预注册要求**，因为缺乏直接比较有/无预注册的AI辅助系统评价在结果报告偏倚方面差异的实证研究。未来研究需要系统评估不同预注册要求（如AI工具使用声明、评估阈值设定、人类监督机制）对减少偏倚的实际效果。

**（5）方法学讨论表明**，将“系统性”简单等同于高质量可能忽视了解释性判断在减少偏倚中的作用[4]。在AI辅助系统评价中，需要平衡自动化流程的效率与人类评审者的批判性反思，避免过度依赖AI工具而引入新的偏倚来源。

总之，协议预注册是减少AI辅助系统评价中结果报告偏倚的重要但尚未充分探索的机制。现有证据支持将传统系统评价的预注册实践扩展到AI辅助场景，并增加AI工具使用的透明度要求。然而，具体的预注册要求需要更多实证研究来验证和优化。
