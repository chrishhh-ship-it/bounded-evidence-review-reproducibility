### 1. 检索与筛选概览

本合成基于提供的八篇摘要级证据（[1]–[8]），这些文献覆盖了气候适应、系统评价方法、数字人文、城市绿化、能源转型等多元领域。然而，直接针对“区分历时语言变化与语料库构成伪像”这一数字人文（DH）核心方法问题的研究在E_q中缺失。现有证据中，[5]虽聚焦中国数字人文研究的文献计量分析，但其主题为研究产出与知识结构，未涉及语言变化的方法论辨析；[4]探讨了数字时代厌女现象的计算语言学方法，但侧重于社会现象而非历时语言学验证。因此，本合成需基于间接相关的方法论讨论（如系统评价的可靠性框架）进行推断性分析。

### 2. 核心主题与证据

E_q中与区分历时变化与语料伪像最相关的主题是**系统评价与自动化提取的可靠性**。[2]提出了一个评估自动化系统诊断数据提取可靠性的基准框架，强调正确性、弃权行为（在不可推导场景中声明不可推导）和可重复性，这为DH研究中区分真实语言变化与语料伪像提供了方法论类比：若一个语言特征在语料库中随时间出现或消失，研究者需排除因语料构成变化（如不同时期文本类型、采样偏差）导致的伪像。[2]中的“弃权行为”概念可类比为当数据不足以支持历时结论时，研究者应明确声明不确定性，而非强行归因。

此外，[4]和[5]展示了计算语言学与文献计量方法在分析大规模文本数据中的应用。[4]通过主题检测和定性分析识别在线厌女现象的研究趋势，其方法可用于追踪语言使用的时间变化，但需注意语料库的构成（如社交媒体平台演变）可能引入伪像。[5]对中国数字人文研究的文献计量分析揭示了研究主题的历时分布，但同样面临数据库覆盖范围变化（如CNKI收录期刊的增减）带来的伪像风险。

### 3. 证据支持的研究方向

基于现有证据，以下研究方向有助于区分历时语言变化与语料伪像：

- **开发类似[2]的可靠性基准**：针对DH中的历时语言分析，建立评估框架，要求研究者报告语料库构成变化（如不同时期文本类型比例、来源稳定性），并设定“弃权”标准——当语料伪像无法排除时，不宣称语言变化。
- **结合[4]的主题检测与[5]的文献计量**：通过主题建模识别语言特征（如词汇、语法结构）的历时分布，同时控制语料库的采样偏差（如不同时期文档长度、作者群体变化）。
- **借鉴[6]的元分析方法**：[6]在评估城市绿化效果时，通过亚组分析和效应修饰因子识别（如树种差异、昼夜差异）来区分真实效应与混杂因素。类似地，DH研究可引入语料库特征（如文本类型、语域）作为修饰因子，检验语言变化是否在不同子语料中一致。

### 4. 摘要级证据的局限

所有八篇证据均为摘要级，缺乏全文细节，这限制了对其方法论的深入评估。具体局限包括：
- **缺乏历时语言学专门方法**：E_q中无一篇文献直接讨论语言变化验证，[2]的可靠性框架虽具启发性，但针对的是诊断数据提取，而非语言特征的时间序列分析。
- **语料库构成信息缺失**：[4]和[5]虽涉及文本分析，但摘要未说明语料库的历时构成（如是否控制文本类型、来源稳定性），无法判断其结论是否受伪像影响。
- **跨领域类比的风险**：将[2]的“弃权行为”或[6]的“效应修饰因子”直接迁移至DH领域，需验证其适用性。例如，语言变化的“真实效应”可能因语料库采样策略（如不同时期收录标准不同）而扭曲，但现有证据未提供此类验证。

### 5. 谨慎结论

基于现有摘要级证据，区分历时语言变化与语料库构成伪像需满足以下条件：研究者应系统记录语料库的历时构成变化（如文本类型、来源、采样策略），并采用类似[2]的可靠性框架，包括预设正确性阈值、明确不可推导场景的弃权标准，以及通过重复运行评估可重复性。同时，需借鉴[4]和[5]的计算方法，但必须控制语料库的混杂因素（如不同时期文档长度、作者群体）。然而，由于E_q缺乏直接相关的DH方法论研究，这些结论主要基于跨领域类比，其有效性需通过专门设计的实证研究验证。未来研究应优先开发针对历时语言变化的语料伪像检测基准，并整合全文级证据以弥补摘要级信息的不足。
