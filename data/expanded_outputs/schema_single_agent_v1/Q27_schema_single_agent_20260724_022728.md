# 面向智慧情报服务的 Benchmark Query Set 与评测协议构建：基于多智能体与领域基准的系统综述

## 1. 检索与筛选概览

本综述围绕“如何构建面向智慧情报服务的 benchmark query set 与评测协议”这一核心研究问题，基于给定的受限证据集 \( E_q \) 展开系统分析。证据集共收录8篇文献，时间跨度为2023年至2026年，涵盖多个前沿研究领域：多智能体协作基准（[1]）、网络安全蓝队能力评估（[2]）、不完美信息博弈基准（[3]）、生物医学大语言模型评测（[4][5][6]）、医疗多智能体问答框架（[7]）以及代码审查智能体基准（[8]）。这些文献从不同维度揭示了构建高质量基准测试集与评测协议所需的设计原则、方法论框架与实证经验，为智慧情报服务领域的基准构建提供了跨领域参考。

## 2. 核心主题与证据

### 2.1 基准构建的设计原则与任务多样性

构建有效的 benchmark query set 需要遵循系统化的设计原则。针对网络安全蓝队操作，[2]提出了SOC-bench的设计原则，强调需要覆盖多任务协同的蓝队能力评估，而非单一任务评测，并指出现有文献缺乏针对多任务蓝队AI的系统化基准。在博弈智能领域，[3]提出的OpenGuanDan基准展示了如何应对不完美信息、大规模信息集与动作空间、合作与竞争混合目标、长时域决策、可变动作空间及动态团队组成等复合挑战。这些设计原则共同指向：智慧情报服务的基准应具备任务多样性、环境动态性与评估维度全面性。

### 2.2 多智能体协作与自主性评估协议

多智能体系统的评测协议需要区分不同自主性层级。[1]提出的Tool-RoCo基准定义了四种LLM范式：集中式协作、集中式自组织、去中心化协作与自组织，并通过工具使用率（合作工具仅占7.09%，激活工具占96.42%）揭示了当前LLM在自适应协调方面的不足。这一发现对智慧情报服务中多智能体协作协议的构建具有重要启示：评测协议应包含对智能体自主调用、协作激活与去激活能力的量化指标。

### 2.3 领域特定评测与证据提取

生物医学领域的基准构建经验表明，评测协议需要结合领域特性。[4]对4种LLM在6项生物医学任务、26个数据集上的评估发现，零样本LLM在小训练集上甚至超越微调模型，但无单一模型在所有任务上占优。[5]在BLURB基准上的评估进一步显示，GPT-4在多项任务中表现最佳，且提示策略的优化（如加入语义相似的示例）能显著提升性能。[6]提出的EvidenceBench则专注于从生物医学论文中提取与假设相关的证据，其创新之处在于采用假设生成与逐句标注的流水线，并验证了人类专家判断的忠实性。

### 2.4 多智能体框架与验证机制

[7]提出的医疗多智能体QA框架展示了如何通过智能体专业化与验证层提升答案可靠性：临床推理智能体、证据检索智能体与精炼智能体协同工作，结合不确定性评分与偏差检测，最终实现87%的准确率。该框架中的证据增强机制将困惑度降至4.13，表明多智能体协作与外部证据检索的结合是提升情报服务质量的有效路径。[8]的代码审查智能体基准则从另一角度提供了评测协议设计思路：通过人类审查生成测试用例，评估智能体审查质量，并发现现有审查智能体仅能解决约40%的任务，凸显了人机协作的潜力。

## 3. 证据支持的研究方向

基于上述证据，面向智慧情报服务的 benchmark query set 与评测协议构建可沿以下方向推进：

**方向一：多层级自主性评测协议设计。** 借鉴[1]的范式分类与[2]的多任务设计原则，构建涵盖集中式、去中心化与自组织等多种协作模式的评测协议，并引入工具使用率、协作激活率等量化指标。

**方向二：领域自适应基准构建方法论。** 参考[4][5][6]在生物医学领域的经验，采用假设生成-证据标注-专家验证的流水线（如[6]的EvidenceBench），并结合提示优化策略（如[5]的语义相似示例）提升基准的领域适配性。

**方向三：多智能体验证与安全机制集成。** 借鉴[7]的模块化多智能体框架，将证据检索、不确定性估计、偏差检测等验证层嵌入评测协议，确保情报服务的可解释性与可靠性。

**方向四：人机协作评估框架。** 基于[8]的发现（智能体审查与人类审查关注不同方面），设计能够量化人机协作增益的评测协议，如通过人类-智能体联合审查的覆盖率与一致性指标。

## 4. 摘要级证据的局限

本综述基于摘要级证据进行分析，存在以下固有局限：首先，摘要信息无法提供方法论的完整细节，例如[1]中工具使用率的计算方式、[2]中蓝队任务的具体设计、[6]中假设生成流水线的算法实现等均无法从摘要中获取。其次，摘要可能省略了关键的实验设置与结果统计，如[4]中零样本LLM超越微调模型的具体条件、[5]中提示策略优化的消融实验结果等。此外，部分文献为预印本（如[2][7]），尚未经过同行评审，其结论的可靠性有待进一步验证。最后，证据集未包含智慧情报服务领域的直接案例，跨领域迁移的适用性需要审慎评估。

## 5. 谨慎结论

综合现有证据，构建面向智慧情报服务的 benchmark query set 与评测协议应遵循以下核心原则：任务多样性（覆盖多类型情报分析任务）、自主性层级区分（从集中式到自组织）、领域自适应设计（结合专家知识与提示优化）、多智能体验证机制（集成证据检索与偏差检测）以及人机协作评估（量化协作增益）。然而，当前证据主要来自博弈、生物医学与网络安全等相邻领域，智慧情报服务的独特需求（如情报源可信度评估、时序推理、对抗性环境等）尚未被充分覆盖。未来研究需在以下方面取得突破：开发专门面向情报分析的多任务基准数据集，设计能够模拟真实情报工作流的动态评测协议，以及建立跨领域可迁移的基准构建方法论。在缺乏直接领域证据的情况下，现有跨领域经验可作为起点，但需通过迭代验证逐步适配智慧情报服务的特殊要求。
