# 人工评估子集应优先覆盖哪些高风险 query 以有效校验自动指标：基于摘要级证据的初步分析

**报告说明**：本报告基于对8篇已筛选论文摘要的初步分析（Method 1 试点阶段），证据层级为摘要级，尚未进行全文精读。所有事实性主张均基于提供的摘要证据。

## 1. 检索与筛选概览
本次分析旨在回答“人工评估子集应优先覆盖哪些高风险 query，才能最有效校验自动指标？”这一问题。从冻结的试点语料库中筛选出8篇相关论文[1-8]。这些文献主要发表于2022年至2026年间，主题集中于**系统综述文献检索、生物医学证据提取、多智能体检索框架以及大语言模型在专业查询中的应用**。分析发现，高风险 query 的特征与**查询的复杂性、领域专业性、对证据可靠性的高要求以及现有自动化工具的常见缺陷**密切相关[1, 2, 3, 8]。

## 2. 核心主题与证据
证据指出，以下几类 query 因其高复杂性或对现有自动指标构成显著挑战，应被视为高风险，并优先纳入人工评估子集：

1.  **系统综述与证据合成中的布尔查询**：系统综述是循证医学中的最高证据形式，但其布尔查询的构建耗时且常常低效[2]。自动生成的查询质量不佳，直接影响检索结果的全面性和可靠性，因此这类查询是校验自动检索指标（如查全率、查准率）的关键高风险对象[2, 4]。

2.  **需要精准引证与避免虚构的学术文献检索**：现有基于大语言模型的文献检索和引用工具经常产生不准确、灰色文献甚至捏造的引文[1]。因此，旨在生成带准确、可核实引文的文献综述草稿的查询属于高风险，人工评估需重点校验其**引用精确度**和**可靠性**[1]。

3.  **涉及复杂语义与多阶段决策的查询**：在电子商务等领域，传统的检索-排序范式与用户的多阶段认知决策过程存在错配，导致处理复杂查询时出现**语义鸿沟**和高决策成本[3]。这类复杂、多意图的查询是检验搜索系统是否超越简单匹配、提供主动决策支持的高风险场景。

4.  **临床与生物医学领域的专业问答**：大语言模型在医疗问答中应用受限，主要问题包括**验证薄弱、证据支撑不足以及置信度信号不可靠**[8]。因此，涉及临床决策、需要从研究文献中进行文档级科学证据提取的查询风险极高[6, 8]。人工评估需聚焦答案的**证据基础、不确定性估计和潜在偏误**[8]。

5.  **依赖专业术语体系（如MeSH）的查询**：在生物医学系统综述中，有效查询的制定依赖于医学主题词等专业术语[4]。自动化术语建议工具的效果需要验证，因此涉及专业术语筛选与组合的查询是评估自动术语扩展或建议指标的高风险对象[4]。

## 3. 证据支持的研究方向
基于摘要证据，以下研究方向与构建有效的人工评估子集相关：

*   **开发混合检索增强生成框架**：针对科学文献综述，可研究动态选择图检索与向量检索的混合智能体框架，以处理不同特性的查询，其性能需要针对复杂查询进行细致评估[5]。
*   **构建面向冲突证据的评估数据集**：在生物医学领域，建立包含冲突证据的文档级证据提取数据集（如CochraneForest），可为评估系统处理复杂临床问题、合成矛盾证据的能力提供基准[6]。
*   **探索多智能体协同的查询处理**：在医疗和气候服务等领域，采用多智能体框架，整合专用大语言模型、证据检索和不确定性评估，是提高复杂专业查询处理可靠性的方向，其输出需人工严格校验[7, 8]。

## 4. 摘要级证据的局限
本报告结论基于摘要级证据，存在以下局限：
*   **细节缺失**：摘要未提供各研究方法的具体评估指标、实验设置和详实结果，无法精确量化不同查询类型的风险等级或自动指标的具体失效模式[1-8]。
*   **验证不明确**：多数摘要未明确说明其提出的方法或指出的问题是如何被验证的，限制了对其主张强度的判断[2, 3, 4, 5, 7]。
*   **领域侧重**：现有证据高度集中于生物医学/临床和电子商务领域，其他高风险领域（如法律、金融）的查询特征可能未被充分覆盖。

## 5. 谨慎结论
基于当前摘要级证据分析，为最有效地校验自动指标，**人工评估子集应优先覆盖以下高风险查询类型**：
1.  **系统综述中的复杂布尔查询**，用于检验查全率与查准率[2, 4]。
2.  **要求高引文准确性的学术检索查询**，用于检验引用精确度与可靠性[1]。
3.  **具有复杂语义和多阶段决策需求的用户查询**，用于检验系统是否克服语义鸿沟并提供决策支持[3]。
4.  **临床与生物医学专业问答查询**，用于检验证据基础、不确定性校准与偏误控制[6, 8]。
5.  **依赖专业术语体系（如MeSH）的查询**，用于检验自动术语建议的有效性[4]。

后续研究需通过全文精读获取更详细的实验数据、评估指标和局限性描述，以进一步细化高风险查询的特征并设计更具针对性的评估协议。
