# Anonymized Query Protocol Confirmation

Two authors constructed the query sets and independently assigned the category and difficulty labels. A third author adjudicated disagreements. The query sets were used directly for generation; no query was revised or removed after pilot outputs were observed.

The main Q01-Q251 query file is timestamped 12 April 2026, the Q01-Q60 pilot file 13 April 2026, and the first preserved corresponding outputs occur after those query-file timestamps. These timestamps corroborate temporal ordering but do not independently prove authorship.

The archive retains the adjudicated labels but not the two pre-adjudication raw label files; no retrospective reliability coefficient is reported. No separately constructed held-out query set is claimed.
