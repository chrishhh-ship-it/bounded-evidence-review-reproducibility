# 多智能体情报系统的应用现状与架构特征：基于摘要级证据的初步梳理

**报告说明**：本报告基于提供的8篇文献摘要（Abstract-Level Evidence）进行证据合成。此为方法论第一阶段（Method 1）的试点研究，结论基于摘要层面的信息，尚未进行全文深度阅读，因此发现具有初步性。

## 1. 检索与筛选概览
本次研究基于一个包含8篇文献的冻结试点语料库进行。文献主题集中于人工智能智能体（AI Agents）、多智能体系统及其在情报、决策和资源管理等领域的应用[1][3][5][6][7][8]。文献发表年份均为2025年，反映了该领域的前沿探讨。筛选出的文献涵盖了智能体协议[1][2]、多智能体系统在智慧城市[3]、算力网络[6]、应急情报[7]等具体场景的应用，以及智能情报技术的宏观论述[5][8]。这些文献为理解多智能体情报系统的构建与应用提供了背景，但直接、明确论述“可重现性”与“基准协议”的摘要级证据为零。

## 2. 核心主题与证据
围绕“多智能体系统”及其在相关领域的应用，摘要证据揭示了以下核心主题：

*   **多智能体系统的广泛应用与宣称价值**：证据表明，基于大语言模型（LLM）的多智能体系统正被部署于解决复杂的现实问题。例如，它们被用作“外部大脑”以增强智能体知识并应对复杂现实问题[1]，应用于智慧城市管理以增强决策支持[3]，用于空天地一体化算力网络以实现计算任务的智能调度和高效分配[6]，以及用于构建粮食安全应急情报体系以提供全生命周期情报支持[7]。
*   **智能体协议与知识库作为技术要素**：有研究专门调查了AI智能体协议[1]，另有研究关注于构建安全的智能体应用[2]。还有研究提出了智能体知识库（Agent KB）系统，该系统利用跨领域经验进行问题解决，并依赖于第三方API调用[4]。这些工作反映了系统构建中对通信、安全与知识共享等基础技术的关注。
*   **智能化情报转型的背景**：情报工作正在经历从传统模式向智能化模式的深刻转型，向“智能即情报”等新模式演进[5]。人工智能被描述为通过智能化手段赋能情报服务与决策，其内在逻辑包括融合创新、场景驱动和战略引领[8]。
*   **特定场景下的方法与指标**：在空天地一体化算力网络资源调度研究中，采用了多智能体强化学习算法，并提及了“资源利用率”和“任务响应时间”作为性能度量指标[6]。在粮食安全应急情报体系构建中，研究论述了基于LBA的体系架构及运作流程[7]。

## 3. 审稿发现
审稿反馈指出，原报告存在超出证据支持范围的核心论点构建问题。具体而言：
1.  证据集中没有任何文献摘要直接讨论“可重现性”或“基准协议”，但原报告却以此为核心组织内容，属于过度推断。
2.  原报告错误地将证据中提到的“协议”[1][2]等同于用于评估的“基准协议”，并将特定性能“指标”[6]的存在作为支持“基准协议”的证据。
3.  原报告基于证据中的技术细节（如依赖API[4]、描述架构[7]）推测其与可重现性的关联，但这些关联在摘要证据中并未被阐明。

因此，本次修订严格依据摘要内容，删除了所有关于“可重现性”和“基准协议”的讨论与推测，将报告焦点重新限定于从摘要中可直接观察到的应用现状与技术特征。

## 4. 修订后结论
基于现有摘要级证据，可以得出以下观察：
1.  **应用广泛**：多智能体系统，特别是LLM驱动的系统，在智慧城市、资源调度、应急情报等多个领域被视为增强决策支持与解决问题的工具[1][3][6][7]。
2.  **技术要素多样**：智能体协议[1][2]、跨领域知识库[4]、特定架构（如云边端架构、分层控制）[6][7]以及多智能体强化学习[6]被作为构建此类系统的关键技术要素。
3.  **性能关注点**：在部分具体应用（如资源调度）中，研究关注“资源利用率”和“任务响应时间”等可量化的性能指标[6]。
4.  **关键信息缺失**：所有提供的摘要证据均未涉及“如何保障多智能体情报系统的可重现性”以及“基准协议”的相关内容。因此，基于当前证据，无法回答原始研究查询。

## 5. 局限性
本报告基于摘要级证据的分析存在明显局限：
*   **缺乏直接证据**：没有一篇文献的摘要涉及“可重现性”或“基准协议”这一具体问题。
*   **细节深度不足**：摘要无法提供关于系统实现、实验设计、评估方法等关键细节。
*   **结论的初步性**：本报告结论仅反映摘要层面信息，需通过获取全文证据进行验证或深化。
